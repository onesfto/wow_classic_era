# ChatWindow 模块

ChatWindow 管理主聊天窗口的尺寸、位置、输入框位置、职业颜色和消息过滤。GW2_UI 负责基础聊天皮肤，本模块只处理 Plus 自己接管的部分。

## 文件

```text
ChatWindow.lua   配置表、默认值、尺寸与 mover 同步
MsgTrim.lua      重复消息裁减
Filter.lua       黑名单、进出频道和裁减过滤器
ClassColor.lua   发言人职业颜色
EditBox.lua      输入框置顶
Options.lua      设置面板
```

TOC 顺序必须保持：`ChatWindow.lua`、`MsgTrim.lua`、`Filter.lua`、`ClassColor.lua`、`EditBox.lua`、`Options.lua`。

## 设置入口

位置：`/gw2` → **聊天** → **窗口布局** 或 **消息管理**。

### 窗口布局

- 启用模块；
- 宽度、高度、X/Y 偏移；
- 输入框移到顶部；
- 聊天按钮位置；
- 聊天窗口渐隐和滚动行为；
- 恢复主聊天窗口默认位置。

### 消息管理

- 聊天历史数量；
- 时间戳；
- 关键词高亮和黑名单；
- 进入/离开频道信息；
- 重复消息裁减；
- BugGrabber 错误提示过滤。

## 位置管理

主窗口使用 GW2_UI mover。设置项改变尺寸或偏移后，会同步到暴雪 FCF 的位置和尺寸数据。`Apply()` 会通过重入锁保护以下操作：

- 设置 `ChatFrame1` 的 user placed 状态；
- 将窗口锚回 mover；
- 更新窗口尺寸；
- 刷新停靠标签和输入框。

只处理 `ChatFrame1`，撕出的独立聊天窗口不在本模块范围内。

输入框置顶时，模块还要重新处理输入框容器背景；关闭该设置通常需要重新加载界面才能完全恢复原生锚点。

## 消息过滤

过滤器始终注册，但是否处理由存档开关决定：

| 功能 | 事件范围 |
|---|---|
| 关键词黑名单 | 频道、说话和大喊消息 |
| 重复内容裁减 | 编号频道消息 |
| 进出频道信息 | `CHAT_MSG_CHANNEL_JOIN` / `LEAVE` |

同一条消息可能会被多个聊天标签分别调用，过滤器需要使用行 ID 或消息缓存避免重复计算。关键词使用 plain 匹配，不把用户输入当作 Lua 模式。

## 配置数据

存档变量为 `GW2_UI_PLUS_ChatWindowSV`。默认值定义在 `ChatWindow.lua`，新增键会在 `InitDB()` 中补齐。设置面板通过 `getter`、`setter` 和 `callback` 直接连接到模块或 GW2_UI 的配置。

## 修改注意事项

1. 不要直接覆盖暴雪聊天函数，优先使用过滤器和安全 hook。
2. 修改 `ChatFrame1` 锚点时必须保留 `applying` 重入锁。
3. 修改输入框位置时同时检查背景容器和临时聊天窗口。
4. 与其他聊天插件同时启用时，同类位置或过滤功能可能互相覆盖。
