## 1️⃣ 一键换装 alaGearMan

**文件位置**: `core.lua`  
**面板ID**: `gw2_ui_plus_gearman`  
**父面板**: `gw2_ui_plus_general` (附加组件)  
**状态**: ✅ 完整集成第三方插件

### 功能说明
集成 alaGearMan 插件，提供一键换装功能，支持多套装备方案快速切换。

### 设置选项

| 选项名称 | 类型 | 说明 |
|---------|------|------|
| 启用 | 开关 | 启用或禁用 alaGearMan 插件（需重载界面）|
| 显示换装栏 | 开关 | 显示换装按钮栏 |
| 按钮分多行 | 开关 | 换装按钮是否分多行显示 |
| 缩放指数 | 滑块 | 调整换装栏整体缩放 |
| 按钮风格 | 下拉 | 选择按钮外观风格 |
| 重置换装栏位置 | 按钮 | 恢复默认位置 |
| 脱光时一并卸下戒指、饰品、披风及耐久为 0 的装备 | 开关 | 一键脱光时的额外行为 |
| 一键脱光按钮位置 | 下拉 | 脱光按钮的显示位置 |
| 自动创建宏 | 开关 | 自动为套装创建宏命令 |
| 在物品提示中显示套装信息 | 开关 | 鼠标悬停装备时显示所属套装 |

### 迁移说明
- ✅ **完整迁移**: 从独立插件 alaGearMan 完整集成
- ✅ **设置面板**: 已适配 GW2_UI 设置框架
- ✅ **兼容性**: 保持原插件所有功能

## 2️⃣ 动作条增强

**文件位置**: `Modules/ActionBar/Options.lua` (及其子模块)  
**面板ID**: `gw2_ui_plus_actionbar`  
**状态**: ✅ 新增功能模块

### 功能说明
为 GW2_UI 的动作条系统提供额外的增强功能，包括全局渐隐、按钮尺寸调整和法师专用动作条。

### 子模块

#### 2.1 全局渐隐系统

| 选项名称 | 类型 | 说明 |
|---------|------|------|
| 启用全局渐隐 | 开关 | 平时把动作条淡化，鼠标移上去才亮起来 |
| 淡出后透明度 | 滑块 | 0-1，0 是完全看不见 |
| 淡出延迟 | 滑块 | 鼠标离开后多久开始变淡（秒）|
| 战斗中 | 开关 | 战斗中不渐隐 |
| 有目标时 | 开关 | 有目标时不渐隐 |
| 施法或引导时 | 开关 | 施法时不渐隐 |
| 生命值不满时 | 开关 | 受伤时不渐隐 |

**迁移说明**: 
- 🆕 **新增功能**: 原 GW2_UI 没有全局渐隐系统
- ⚠️ **与本体独立**: 和本体动作条的"显示"设置是两套机制，透明度会相乘

#### 2.2 按钮尺寸调整

| 选项名称 | 类型 | 说明 |
|---------|------|------|
| 动作条 1（主动作条）| 滑块 | 主动作条的按钮大小 |
| 动作条 2-8 | 滑块 | 其他动作条的按钮大小 |
| 恢复默认 | 按钮 | 主动作条回到 48，其余回到 36 |

**迁移说明**:
- 🆕 **新增功能**: 提供细粒度的按钮尺寸控制
- 📊 **默认值**: 主条 48，其他 36

#### 2.3 法师动作条

| 选项名称 | 类型 | 说明 |
|---------|------|------|
| 启用法师动作条 | 开关 | 把传送、传送门、造食物/水、魔法宝石收进独立动作条 |
| 竖向排列 | 开关 | 按钮上下排，弹出条往左边展开 |
| 按钮尺寸 | 滑块 | 调整按钮大小 |
| 收集的法术 | 多个开关 | 控制哪些法术被收集 |

**迁移说明**:
- 🆕 **职业专属**: 为法师职业设计的专用功能
- 💡 **智能收集**: 自动识别同类法术（如不同等级的传送）
- 📍 **可移动**: 在 HUD 移动模式（/gw2 → 移动界面）中调整位置

- 左上、上、右上
- 左中、右中

- 🆕 **全新功能**: 独立的插件按钮管理系统
- 🔗 **独立运行**: 不依赖 GW2_UI 的小地图模块

## 🔧 开发者注意事项

### 面板注册流程
所有设置面板通过以下方式注册：
1. 在 `PLAYER_ENTERING_WORLD` 事件后获取 GW2_UI 的设置标签框架
2. 使用 `CreateFrame("Frame", nil, parent, "GwSettingsPanelTmpl")` 创建面板
3. 设置 `panelId`、`header`、`sub`、`breadcrumb` 等属性
4. 使用 `AddOption()`、`AddOptionDropdown()`、`AddOptionSlider()` 等方法添加选项

### 依赖关系
- 所有模块都依赖 `GW2_ADDON.GetSettingsTabFrame()` 存在
- 部分模块有内部依赖（如 ActionBar 的子模块）
- 使用 `dependence` 参数实现选项间的依赖关系

### 保存变量
- 主体使用 `GW2_UI_PLUS_SV` 全局表存储设置
- 各模块可能使用独立的 SavedVariables
- alaGearMan 使用 `__ala_meta__` 全局表
