# GW2_UI_PLUS 配置说明

## 访问设置

游戏内输入 `/gw2` 打开 GW2_UI 设置面板，在「附加组件」分类下找到各模块设置。

## 动作条 (ActionBar)

### 通用设置

#### 启用 GW2 UI 动作条
- **类型**: 开关
- **默认**: 开启
- **说明**: GW2 UI 原生总开关，需要重新加载界面

#### 全局渐隐
- **类型**: 开关
- **默认**: 关闭
- **说明**: 鼠标离开后统一降低所选动作条的透明度

#### 淡出后透明度
- **类型**: 滑块 (0.00 - 1.00)
- **默认**: 0.40
- **说明**: 渐隐后的透明度，0 为完全透明

#### 淡出延迟
- **类型**: 滑块 (0.0 - 5.0 秒)
- **默认**: 0.5
- **说明**: 鼠标离开后多久开始渐隐

#### 战斗中不渐隐
- **类型**: 开关
- **默认**: 开启
- **说明**: 战斗中保持动作条完全可见

#### 参与渐隐的动作条
- **类型**: 多选
- **默认**: 全选
- **说明**: 选择哪些动作条参与渐隐效果

### 主动作条

#### 显示主动作条
- **类型**: 开关
- **默认**: 开启

#### 尺寸
- **类型**: 滑块 (24 - 60)
- **默认**: 48
- **说明**: 按钮大小（像素）

#### 间距
- **类型**: 滑块 (0.0 - 20.0)
- **默认**: 2.0
- **说明**: 按钮之间的间距

#### 按钮数
- **类型**: 滑块 (1 - 12)
- **默认**: 12
- **说明**: 显示的按钮数量

#### 行按钮数
- **类型**: 滑块 (1 - 12)
- **默认**: 12
- **说明**: 每行显示几个按钮

#### 中间空隙
- **类型**: 滑块 (0 - 200)
- **默认**: 108
- **说明**: 主动作条中间的空隙宽度

#### 快捷键
- **显示快捷键**: 开关，默认开启
- **位置**: 下拉框（左上/上/右上/居中/左下/下/右下）
- **字体大小**: 滑块 (8 - 48)，默认 12

#### 宏名称
- **显示宏名称**: 开关，默认开启
- **位置**: 下拉框
- **字体大小**: 滑块 (8 - 48)，默认 12

### 多动作条 (2-8)

每个多动作条都有独立设置：

#### 显示
- **类型**: 开关
- **说明**: 是否显示该动作条

#### 尺寸
- **类型**: 滑块 (24 - 60)
- **默认**: 36

#### 间距
- **类型**: 滑块 (0.0 - 20.0)
- **默认**: 2.0

#### 按钮数
- **类型**: 滑块 (1 - 12)
- **默认**: 12

#### 行按钮数
- **类型**: 滑块 (1 - 12)
- **默认**: 根据条号不同，2-3 或 6

#### 快捷键/宏名称
- 同主动作条设置

## 重置配置

### 重置单个模块

在对应设置面板点击「恢复默认」按钮。

### 重置所有配置

1. 退出游戏
2. 删除上述存档文件
3. 重新启动游戏

## 配置备份

建议定期备份 `SavedVariables` 目录。

## 配置同步

跨角色同步：部分设置存储在账号级别，自动同步。

跨服务器同步：需要手动复制存档文件。

## 常见问题

### 设置不生效

1. 确认已点击「应用」或「确定」
2. 某些设置需要 `/reload` 重新加载界面
3. 检查是否有冲突的其他插件

### 设置丢失

1. 检查存档文件是否存在
2. 确认游戏正常退出（非强制关闭）
3. 检查文件权限

### 无法打开设置面板

1. 确认 GW2_UI 主插件已启用
2. 输入 `/gw2` 检查是否有 Lua 错误
3. 禁用其他可能冲突的插件

## 高级配置

### 直接编辑存档文件

不推荐，但可以批量修改配置。

格式为 Lua 表：

```lua
GW2_UI_PLUS_ActionBarSV = {
    ["mainBarSize"] = 48,
    ["fadeEnable"] = true,
}
```

编辑后需要重启游戏。

## 性能调优

### 降低性能影响

1. 关闭不需要的模块
2. 减少渐隐效果使用
3. 降低更新频率（如性能监控条）
4. 限制聊天消息数量

### 优化建议

- 动作条尺寸: 使用默认值，过大会增加渲染负担
- 渐隐延迟: 0.5 秒是平衡点
- 聊天消息数: 500 条对大多数情况足够
