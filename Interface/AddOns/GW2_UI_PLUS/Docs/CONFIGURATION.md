# GW2_UI_PLUS 配置说明

## 进入设置

在游戏内输入 `/gw2`，打开 GW2_UI 设置窗口。GW2_UI_PLUS 的入口分布在以下标签页：

| 标签页 | 主要内容 |
|---|---|
| 框体 | 玩家、目标、目标的目标、宠物的布局、资源、光环和渐隐 |
| 聊天 | 聊天增强、窗口布局、频道按钮、消息管理 |
| 队伍 | 小队、团队及团队子框体 |
| 组件 | 通用功能、微型系统菜单、小地图、世界地图和附加组件 |
| 编辑模式 | 进入 GW2_UI HUD 移动界面 |

附加组件下的主要页面包括：一键换装、动作条、频道按钮、冷却闪烁、聊天窗口、界面皮肤、插件收纳和工具条。

设置页面的具体排列规则见 [设置界面排版规范](SETTINGS_LAYOUT_GUIDE.md)，设置架构见 [SETTINGS_ARCHITECTURE.md](SETTINGS_ARCHITECTURE.md)。

## 功能分组

### 动作条

- 全局渐隐、渐隐透明度和延迟。
- 主动作条与多动作条的按钮尺寸、数量、列数和间距。
- 快捷键、宏名称和玩家资源相关布局。
- 法师专用动作条、图腾条、姿态条和宠物条。

### 聊天

- 聊天增强：GW2 风格、链接、复制、频道名称和职业颜色。
- 窗口布局：主聊天窗口尺寸、位置、输入框位置和按钮位置。
- 频道按钮：显示频道、插件快捷入口、位置、缩放和自动显隐。
- 消息管理：历史数量、时间戳、关键词、重复消息和进出频道信息。

相关命令：`/gwcb`。

### 组件与工具

- 通用功能：快速拾取、任务处理、商人交互等开关。
- 工具条：快捷栏、队伍管理、标记条和性能条。
- 小地图：插件按钮收纳入口。
- 世界地图：坐标、探索显示、兴趣点和地图增强。
- 冷却闪烁：图标尺寸、动画参数和技能名称位置。

相关命令：`/dcp`、`/cooldownpulse`。

### 皮肤与社交

- 专业/制造面板、邮件、任务日志。
- BetterBags、BugSack、MailLogger、NovaWorldBuffs、Myslot 等第三方插件皮肤。
- 好友、公会、忽略、团队和 Who 列表的界面调整。

## 存档

存档由插件清单声明，位于账号或角色的 `WTF/Account/.../SavedVariables/` 目录。当前主要入口包括：

```text
alaGearManSV
GW2_UI_PLUS_SV
GW2_UI_PLUS_ChatBarSV
GW2_UI_PLUS_ChatWindowSV
GW2_UI_PLUS_ActionBarSV
GW2_UI_PLUS_PlayerStatusSV
GW2_UI_PLUS_PlayerFaderSV
GW2_UI_PLUS_TargetFaderSV
GW2_UI_PLUS_CooldownPulseSV
```

模块会在初始化时补齐缺失的默认值，不会主动覆盖已有配置。

## 恢复默认与备份

- 单个页面：使用页面提供的“恢复默认”按钮。
- 动作条、工具条和 HUD 移动器：恢复默认时会同时还原对应位置。
- 全部重置：退出游戏后备份并删除 `GW2_UI_PLUS.lua` 及相关插件存档，再重新启动游戏。
- 修改前建议复制整个 `SavedVariables` 目录；不要在游戏运行时直接编辑存档。

## 常见问题

### 页面没有出现

确认 `GW2_UI` 已启用，且 `GW2_UI_PLUS.toc` 与模块文件位于同一插件目录。第三方插件页面只在对应插件加载时出现。

### 设置没有立即生效

部分 GW2_UI 原生设置和受保护框体布局需要重新加载界面；页面自身会在需要时提示。战斗中涉及保护框体的位置操作会延后到允许修改时执行。

### 设置恢复后位置仍不对

先关闭其他会移动同一框体的插件，再使用对应页面的恢复默认入口。聊天窗口位置同时受到暴雪 FCF 和 GW2_UI mover 管理。

### 如何查找某个配置

先从 [设置面板清单](SETTINGS_PANELS.md) 找到页面，再到对应模块的 `Options.lua` 查看实际选项名和默认值。
