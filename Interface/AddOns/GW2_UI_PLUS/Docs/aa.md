### 一、 左右 (Left/Right) 布局全列

**单行模式 (当行)**
```text
12345 # 67890
1234 # 5678
123 # 456
12 # 34
1 # 2
```

**双行模式 (双行)**
```text
13 # 57
24 # 68

1 # 3
2 # 4
```

### 二、 上下 (Up/Down) 布局全列

依循 `#` 作为中心锚点（恒定位于数字 `1` 右侧第 4 格）且末位数字 `0` 始终与 `#` 垂直对齐的物理规律，10 个按键的全排布序列如下：

**上排 9，下排 1**
```text
123456789
    #
    0
```

**上排 8，下排 2**
```text
12345678
    #
   90
```

**上排 7，下排 3**
```text
1234567
    #
  890
```

**上排 6，下排 4**
```text
123456
    #
 7890
```

**上排 5，下排 5**（视觉居中平衡态）
```text
12345
    #
67890
```
