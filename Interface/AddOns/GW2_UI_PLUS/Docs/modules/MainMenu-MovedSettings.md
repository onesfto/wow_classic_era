# GW2_UI_PLUS 设置迁移说明

为了更好地组织界面选项，`GW2_UI_PLUS` 将 `GW2_UI` 原版中的部分设置项进行了移动和重组。
所有被移动的设置已在原版界面中被**完全隐藏**，以确保原版设置面板的整洁，并防止重复设置带来的冲突。

以下是所有被移动/重组的原始设置及其在 `GW2_UI_PLUS` 中的新位置：

## 一、 移动到「玩家」新页面

`GW2_UI_PLUS` 重构了玩家相关的设置，隐藏了原有的数个独立子页面，并按功能拆分为新的同级页面。每个页面中的选项均独占一行：

### 1. 血球和贴图
原先散落的血球与 HUD 贴图设置统一移动至 **「玩家」 -> 「血球和贴图」**：
- **动作条贴图 (HUD_BACKGROUND)** (原：综合 -> 动作条贴图)
- **血球贴图 (HUD_SPELL_SWAP)** (原：玩家 -> 综合 -> 血球贴图)
- **显示位移条 (showDodgebar)** (原：玩家 -> 综合 -> 显示位移条)
- **位移条追踪法术 (PLAYER_TRACKED_DODGEBAR_SPELL)** (原：玩家 -> 综合 -> 位移条法术 ID)

### 2. 施法条
- **原版页面**：**设置面板 -> 玩家 -> 施法条**（该独立页面已隐藏）
- PLUS 新位置：**玩家 -> 施法条**
- 包含启用、跳数、高级施法条、法术队列窗口、宽度和高度选项。

### 3. 能量条
- PLUS 新位置：**玩家 -> 能量条**
- 包含能量/法力回复提示、5 秒规则、仅战斗显示提示、额外能量条和数值显示选项。
- **启用额外能量条 (POWERBAR_ENABLED)** 原位于玩家综合页面。

### 4. 资源条
- **原版页面**：**设置面板 -> 玩家 -> 职业资源条**（该独立页面已隐藏）
- PLUS 新位置：**玩家 -> 资源条**
- 包含启用、数值显示、锚点、侧边、X/Y 偏移、间距和仅战斗显示选项。

### 5. 经验槽
- **启用经验槽 (XPBAR_ENABLED)** (原：界面 -> 经验槽 -> 启用)
- **任务经验值百分比 (QUEST_XP_PERCENT)** (原：界面 -> 经验槽 -> 任务经验值百分比)
- PLUS 新位置：**玩家 -> 经验槽**

### 6. 光环 (增益/减益)
原版的 **「设置面板 -> 玩家 -> 光环」** 页面已被完全拆分并隐藏，现在选项按增益和减益被分别归类：
- **原版页面**：**设置面板 -> 玩家 -> 光环**（该独立页面已隐藏）
- **增益光环**
  - PLUS 新位置：**玩家 -> 增益光环**
- **减益光环**
  - PLUS 新位置：**玩家 -> 减益光环**

## 二、 移动到「框体」
以下几个界面组件的设置，已从原版的 **「设置面板 -> 界面」** 中被整体移动到新的 **「框体」**（PLUS 统一单位框体及 HUD 界面）菜单下：
- **微型系统菜单** (hud_microbar)
- **微缩地图** (hud_minimap)
- **世界地图** (hud_worldmap)

*注：以上原版菜单项已被完全隐藏。*

## 三、 移动到「动作条」

### 1. 图腾条
在 `GW2_UI_PLUS` 中，原版位于玩家设置下的图腾条被统一归入动作条设置中进行管理：
- **图腾条**
  - GW2UI 原位置：**设置面板 -> 玩家 -> 图腾条**
  - PLUS 新位置：**动作条 -> 图腾条**
  - *注：在此处可以独立控制图腾条的启用状态、增长方向、排序方向、按钮尺寸和间距，并且其透明度现在可以受到全局动作条渐隐特性的控制。*

## 四、 移除及逻辑变更

*注：原版 **「设置面板 -> 玩家 -> 综合」** 独立页面已被完全隐藏，其内选项已分散至 PLUS 的各个对应模块中。*

### 1. 玩家框体样式
- **将玩家框体样式变为目标框体样式 (PLAYER_AS_TARGET_FRAME)**
  - GW2UI 原位置：**设置面板 -> 玩家 -> 综合 -> 将玩家框体样式变为目标框体样式**
  - **变更说明**：该选项已被完全 **移除**。`GW2_UI_PLUS` 重构了普通玩家框体的逻辑，不再依赖于目标框体样式，并且原本依赖于此选项的各种宽高缩放设置，现在均可独立于样式进行设置。

### 2. 玩家框体切换
- **普通玩家框体 (HEALTHGLOBE_ENABLED)**
  - GW2UI 原位置：**设置面板 -> 玩家 -> 综合 -> 启用**
  - **变更说明**：在 `GW2_UI_PLUS` 中，原本控制是否显示整个球状界面的选项，现在统一位于 **「玩家」 -> 「综合」 -> 「启用」**。该开关现在专注负责精确控制是否启用 **普通玩家框体**，而不再捆绑控制血球、位移条等其他独立组件的开关状态。
