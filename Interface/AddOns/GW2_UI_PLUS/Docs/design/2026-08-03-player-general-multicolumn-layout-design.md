# 玩家综合多栏排版设计

## 目标

调整“框体 > 玩家 > 综合”页面的前两组选项，使常用显示设置按三栏和两栏紧凑排列，并完全复用“动作条 > 综合”现有的多栏布局机制。

## 页面布局

页面顶部按以下顺序显示：

```text
启用                                           独占一行
显示另一种背景材质 | 显示职业颜色 | PvP指示器   三栏
显示生命值数值     | 生命条材质                  两栏
```

“启用”继续作为主开关独占一行，并保留主开关后的分隔线。上述两行之后的尺寸及其他设置维持现有顺序，并继续独占一行。

## 实现约束

使用 `ActionBarOptionsUtils.InitializePanel` 构建玩家综合页面的滚动列表。三个布尔选项连续设置 `gwPlusColumns = 3`，两个下拉选项连续设置 `gwPlusColumns = 2`，由动作条现有布局代码计算列宽、创建行并应用紧凑下拉框样式。

玩家综合页面继续复用 GW2_UI 已创建的原生选项和控件。多栏初始化器需要把复用的原生控件纳入当前面板的控件列表，以便现有刷新流程能够更新开关、下拉框和依赖状态；不得复制设置定义或创建另一套玩家设置。

## 行为与兼容性

本次只调整设置页面布局，不修改原生设置键、默认值、SavedVariables、回调、依赖条件或游戏内框体行为。以下设置仍由原有逻辑控制：

- `PLAYER_AS_TARGET_FRAME_ALT_BACKGROUND`
- `player_CLASS_COLOR`
- `PLAYER_SHOW_PVP_INDICATOR`
- `PLAYER_UNIT_HEALTH`
- `playerFrameHealthBarTexture`

经典怀旧服中被 GW2_UI 隐藏的其他版本专属选项仍保持隐藏。玩家资源拆分页面及动作条页面自身的布局不受影响。

## 验收标准

1. “启用”独占第一行，主开关样式和分隔线正常。
2. “显示另一种背景材质”“显示职业颜色”“PvP指示器”按顺序显示在同一行的三栏中。
3. “显示生命值数值”“生命条材质”按顺序显示在下一行的两栏中。
4. 两个下拉框使用动作条现有的紧凑多栏下拉布局，文本和控件不重叠。
5. 后续选项顺序和独占行布局不变。
6. 五个原生设置的取值、回调和依赖状态与排版前一致。
7. 自动回归测试覆盖 `3 + 2` 列标记、动作条初始化器复用及原生控件刷新登记，相关既有测试全部通过。
