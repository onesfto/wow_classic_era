# 世界地图坐标横向底栏设计

## 目标

将世界地图坐标组件从居中的双行小面板改为固定在地图内容区底部的横向底栏；设置中仅提供启用开关。

## 范围

- 坐标栏以 `WorldMapFrame.ScrollContainer` 的 `BOTTOMLEFT` 和 `BOTTOMRIGHT`（纵向偏移均为 `8`）横跨底部，不增加、不读取也不保存位置或偏移设置。
- 底栏横跨地图内容区：光标坐标左对齐，玩家坐标右对齐，二者同一行显示。
- 保留现有鼠标与玩家坐标取值，以及每 0.2 秒更新的节流逻辑。
- 将设置文本从「显示双行坐标」改为「启用坐标」。

## 非目标

- 不改动世界地图的其他增强功能、数据源或刷新频率。
- 不提供拖动、位置、偏移、字体、颜色或尺寸设置。

## 验收标准

1. 启用坐标时，世界地图底部显示一条横向坐标栏，左侧为光标坐标、右侧为玩家坐标。
2. 坐标栏始终固定在现有底部锚点，配置中没有可改变其位置的项目。
3. 关闭「启用坐标」后，坐标栏隐藏；坐标数据更新逻辑保持原有节流频率。
