# 世界地图增强设计

## 目标

在 `GW2_UI_PLUS` 的“组件 → 世界地图”页面中提供 Classic Era 世界地图增强功能。功能和数据以本地 `Leatrix_Maps` 为迁移来源，但由 PLUS 的设置、运行模块和视觉风格统一管理。

## 范围

本次包含：

- 未探索区域显示，以及颜色和透明度设置。
- POI：副本与团队入口、同阵营和敌对阵营交通点、灵魂医者、可点击区域出口。
- 区域推荐等级、副本等级和最低钓鱼技能。
- 玩家换区时自动更新地图区域。
- 地图在静止/移动时使用不同透明度，鼠标悬停时保持静止透明度。
- 队伍和团队图标职业染色。
- 大陆地图隐藏城镇和城市图标。
- 战场地图的队友显示、位置与尺寸、透明度、最大缩放、自动居中、玩家箭头和队友图标尺寸。
- 以两行形式显示鼠标坐标和玩家坐标，替换当前合并成一行的坐标展示。

世界地图窗口自身的拖动、缩放与位置持久化继续使用 `GW2_UI` 既有实现，不重复实现。

## 模块边界

新增 `Modules/WorldMap/`：

- `Data.lua`：从 Leatrix 提取的探索图块、POI 和等级静态数据；只保存数据，不包含界面逻辑。
- `Core.lua`：世界地图 POI、探索图层、自动换区、自动透明度、地图内部缩放记忆、居中玩家、图标调整与城市图标过滤。
- `Battlefield.lua`：仅处理 `BattlefieldMapFrame` 的可移动、尺寸、透明度、缩放、居中和队友图标。
- `Coordinates.lua`：替换依赖插件现有坐标显示，提供鼠标与玩家各一行的显示和刷新节流。
- `Options.lua`：将 PLUS 的设置项加入现有 `hud_worldmap` 面板，并把用户操作转换为 Core/Battlefield 的刷新调用。

`GW2_UI_PLUS.toc` 在设置模块前加载世界地图模块，确保设置页创建前已注册配置接口。

## 设置与数据流

全部新设置放在 `GW2_UI_PLUS_SV.worldMap`，首次使用时写入默认值。设置页分为四组：

1. 地图内容：未探索区域、色调、POI 子项、等级、钓鱼等级、城镇/城市图标。
2. 地图行为：自动换区、自动居中、内部缩放记忆、额外缩放、移动/静止透明度和鼠标悬停例外。
3. 图标与坐标：职业染色、队友/玩家箭头大小、双行坐标显示。
4. 战场地图：启用、解锁、尺寸、透明度、最大缩放、自动居中、玩家箭头和队友图标大小。

选项回调只刷新受影响模块：POI 更改时刷新数据提供器；色调更改时刷新探索图层；尺寸或透明度更改时立即更新对应地图框体。需要注册事件或 Hook 的功能在初始化时一次性安装，运行时由设置决定是否执行，避免重复 Hook。

## 兼容性与安全

- 对 `WorldMapFrame`、`BattlefieldMapFrame`、数据提供器和 Pin 的访问均进行存在性检查。
- 使用 `hooksecurefunc` 和新建数据提供器，不覆盖暴雪关键逻辑。
- `OnUpdate` 只用于已有的坐标、居中与透明度需求，并以 0.1 至 2 秒节流。
- 不修改 `GW2_UI` 文件；PLUS 在运行时接管坐标显示并隐藏原坐标框，避免重复展示。
- 继续兼容 Questie；POI 使用独立 Pin 模板，尺寸不改变其他插件的 Pin。
- 地图和战场图 API 在 Classic Era 不可用时静默跳过，保证加载安全。

## 测试策略

- 新增 shell 回归脚本，检查 TOC 加载顺序、设置注册、数据提供器、探索覆盖、POI 筛选、自动换区、坐标双行和战场地图关键保护条件。
- 可单元化的设置归一化和 POI 筛选函数使用 Lua stub 测试。
- 游戏内验证：打开地图、切换区域、切换每类 POI、移动/静止、队伍与团队、战场地图、Questie 共存，以及 `/console taintLog 1` 下的非战斗和战斗后交互。

## 验收标准

- 所列设置均只出现在“组件 → 世界地图”中，并保存到 PLUS 的 SavedVariables。
- 各项开关可独立生效，关闭后恢复暴雪默认显示或不再施加增强。
- 坐标始终是独立的鼠标行与玩家行，且地图隐藏后停止刷新。
- 现有世界地图皮肤、拖动缩放及其保存位置功能保持可用。
- 所有仓库回归脚本与新增世界地图回归脚本通过；游戏内验证清单无 Lua 错误和污染问题。
