# 框体颜色入口迁移设计

## 目标

将原生 GW2_UI「单位框体 → 综合」中的全局反应颜色设置迁移到
GW2_UI_PLUS 的「框体」标签页，并命名为「框体颜色」。

## 范围

- 捕获原生 `unitframes_general` 面板。
- 从原生设置菜单移除该子菜单项。
- 在 Plus「框体」左侧主菜单的「宠物」之后新增顶层「框体颜色」入口。
- 打开该入口时，将面板标题设为「框体」，面包屑设为「框体颜色」，
  并保留原有的友方、敌对、已被攻击单位颜色选项。

## 不在范围内

- 不修改颜色选项的存储键、默认值或回调。
- 不迁移原生「单位框体」中的其他页面。
- 不调整现有玩家、目标、宠物或队伍菜单结构。

## 验收与测试

- 原生菜单中不再显示 `unitframes_general`。
- Plus「框体」菜单显示「框体颜色」，且可打开该原生面板。
- 面板标题与面包屑显示为「框体 → 框体颜色」。
- 在模拟菜单数据中，过滤后仅移除该子菜单并保留其他条目。
- Lua 语法检查与框体设置回归脚本通过。
