# 框体标题布局统一设计

## 目标

先仅统一 Plus「框体」标签页中的大标题与小标题布局，作为其他 Plus 设置页迁移前的视觉验证。

## 规则

- 大标题宽度按完整文本测量，不保留额外空白，也不截断文本。
- 小标题非空时，清除模板默认锚点，固定在大标题右侧 36 像素处。
- 小标题为空时，不显示任何文本。

## 范围

- 修改 `Modules/Settings/Settings.lua` 内框体页使用的 `SetPanelText`。
- 仅影响玩家、目标、目标的目标、宠物与框体颜色页面。

## 不在范围内

- 不修改 `PartyTab.lua`、动作条、组件或其他 Plus 设置页。
- 不修改 GW2_UI 原生设置模板。
- 不修改标题字体、颜色、说明文字或选项布局。

## 验收

- 长大标题的显示宽度等于其完整文本宽度。
- 有小标题的页面在大标题后固定保留 36 像素间距。
- 无小标题时不产生可见的小标题文本。
- 现有框体设置回归脚本和 Lua 语法检查通过。
