# 综合菜单与通用便利功能设计

## 目标

在 GW2_UI_PLUS 的“组件”标签中把“综合”作为第一项，用统一的设置页提供任务、商人、拾取与画面便利功能。已有的 GW2_UI 自动卖灰和自动修理只在该页重新暴露其原设置，不产生第二套逻辑或存档字段。

## 范围

### 自动化

- 自动接受可接受任务。
- 自动完成并交付已经完成且不需要付费、没有奖励选择的任务。
- 自动选择唯一且安全的 NPC 对话项；银行、商人、飞行管理员、训练师和战场管理员等服务对话不会被自动跳过。
- 按住 Shift 时临时跳过自动任务与自动对话，便于手动选择。

### 商人

- 在综合页复用 `GW2_UI` 的 `BAG_VENDOR_GRAYS` 和 `AUTO_REPAIR` 设置。
- 拦截等级低于客户端最高等级的角色发起的交易；交易窗口打开时使用对方等级判定，满足条件立即取消并在聊天框说明原因。
- 提供批量购买：Shift 点击商人物品后显示数量框，显示单组数量、背包可容纳数量、货币/代币可购买数量和商人库存上限；提供“一组”“最多”和自定义数量，并在购买量大于默认一组时二次确认。

### 拾取

- 加快自动拾取时把 `autoLootRate` 设为 `0`。
- 仅自动拾取未锁定、未达到当前队伍分配阈值的物品；任务物品允许拾取。
- 自动拾取前检查可用背包槽位或同类物品的剩余堆叠空间。
- 背包不足、唯一物品上限、锁定物品、队长分配或阈值以上物品保留原生拾取窗口。
- 禁用后恢复该 CVar 在启用前读取到的值，不假设固定默认值。

### 画面

- 反河蟹：设置 `overrideArchive = 0`。选项说明必须提示玩家完全退出战网和 WoW 后才生效。
- 天气密度：下拉选项 `0` 至 `3`，显示为小雨、中雨、大雨、暴雨，并同步写入 `weatherDensity` 和 `RAIDweatherDensity`。
- 血液效果：下拉选项 `violenceLevel` 的 `0` 至 `5`，显示为无、略微、少量、普通、暴力、很暴力。
- 禁用屏幕泛光：控制 `ffxGlow`。
- 禁用屏幕特效：同时控制 `ffxDeath` 与 `ffxNether`。
- 最大镜头距离：Classic Era 启用时写入 `cameraDistanceMaxZoomFactor = 2.6`，并在 `PLAYER_ENTERING_WORLD` 后重申一次；关闭后恢复启用前的客户端值。

## 不在范围内

- 不复制或嵌入 Leatrix_Plus、Pig、BuyEmAllClassic 或 AdvancedInterfaceOptions 的源码、素材和 SavedVariables。
- 不提供通用 CVar 浏览器、完整 CVar 备份恢复或其他未列出的 Leatrix/Pig 功能。
- 不改变 GW2_UI 原有的自动卖灰、自动修理、背包、动作条与聊天实现。

## 架构

新增 `Modules/General/`，按职责拆分为设置、自动任务、商人、快速拾取和画面 CVar 五个文件。模块通过 `GW2_UI_PLUS_SV.general` 保存 Plus 自身设置；启动时合并默认值，每项功能只在启用时注册对应事件。

`Modules/General/Options.lua` 构建“综合”面板，面板标题沿用“附加组件 / 综合”。`core.lua` 在构造附加组件子面板时先插入该面板，所以 `ComponentsTab.lua` 无需改变排序算法即可把它显示为第一项。

所有 CVar 写入先通过 `GetCVarDefault` 或 `GetCVar` 检查支持性。不存在的 CVar 对应选项隐藏，不报错；需要重启的 `overrideArchive` 只保存提示，不尝试在运行中强制刷新客户端资源。

## 安全与兼容性

- 不在战斗中执行交易取消、商人购买、领取物品或改动可能受保护的原生框体；战斗内仅保持状态，脱战后恢复可执行行为。
- 自动交任务不会处理金币需求、奖励多选或不完整任务，避免错误消耗货币或选错奖励。
- 批量购买逐次调用原生购买 API，并在库存、背包或货币变化时立即停止；不会使用无间隔循环。
- 快速拾取保留队伍分配、锁定和高品质物品的原生决策流程。

## 验收标准

1. “组件”菜单的第一项为“综合”，首次打开时展示该页。
2. 综合页中的自动卖灰与自动修理能读写 GW2_UI 当前设置，且不创建同义的 Plus 设置字段。
3. 每个新增自动化、商人、拾取与画面开关在重载后保持设定。
4. 自动任务在安全任务上生效，在金币需求和奖励多选任务上不自动交付；按 Shift 可临时禁用自动行为。
5. 批量购买不会超过库存、货币或背包容量，并会在大额购买前要求确认。
6. 快速拾取不自动取得需要分配、锁定或无法装入背包的物品。
7. 画面选项只写入客户端存在的 CVar；天气同时作用于普通与团队/副本天气；反河蟹显示重启提示。
8. 静态回归脚本覆盖 TOC 加载顺序、设置页第一项、事件/CVar 常量与安全分支；在 Classic Era 客户端中手动验证一次。
