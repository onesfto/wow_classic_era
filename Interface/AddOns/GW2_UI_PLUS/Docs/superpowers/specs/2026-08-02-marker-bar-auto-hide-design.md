# 标记条自动隐藏设计

## 目标

为工具条的标记条增加三个独立的自动隐藏开关，避免在无法实际标记时占用界面空间。

## 配置

`Toolbar.markerBar` 增加以下布尔配置，默认均为 `true`：

- `hideWhenNoPermission`：玩家没有设置团队标记权限时隐藏。
- `hideWhenNoTarget`：当前没有目标时隐藏。
- `hideWhenSolo`：未处于队伍或团队时隐藏。

标记条设置页提供对应三个复选项，并纳入该组件的重置操作。

## 显示逻辑

标记条仅在组件已启用，且所有已开启的隐藏条件均不满足时显示：

- 无权限的判定继续沿用现有逻辑：五人小队可用；团队中仅队长或助理可用。
- 无目标以 `UnitExists("target")` 判定。
- 单人以 `IsInGroup()` 判定。

任一条件未启用时，不参与隐藏判定。标记按钮原有的启用、灰显和透明度反馈保持不变，以便关闭自动隐藏后仍能识别不可用原因。

## 刷新与安全性

继续使用现有目标变更、队伍名单变更和队长变更事件刷新；显示切换仍通过既有的非战斗队列执行，避免修改受保护框体时产生战斗锁定问题。移动组件时沿用现有移动器行为。

## 验证

回归检查覆盖默认配置、三个设置项及重置项，以及显示条件对开关组合的约束。所有已有工具条回归脚本也应保持通过。
