# 玩家状态设置拆分设计

## 目标

将“框体 > 玩家 > 状态条”组合页面拆分为 5 个同级菜单，移除“状态条”入口，使每类设置拥有独立面板，并让每个选项独占一整行。

## 菜单结构

玩家菜单按以下顺序显示：

1. 综合
2. 血球和贴图
3. 施法条
4. 能量条
5. 资源条
6. 经验槽
7. 渐隐
8. 增益光环
9. 减益光环

不再注册或显示“状态条”菜单。

## 面板划分

原“状态条”页面中的 5 个分组分别迁移到同名独立面板：

- “血球和贴图”面板保留血球启用、缩放、动作条贴图、血球贴图、位移条及位移条技能选项。
- “施法条”面板保留启用、跳数、高级施法条、法术队列窗口、宽度及高度选项。
- “能量条”面板保留能量或法力回复提示、5 秒规则、仅战斗显示提示、额外能量条及数值显示选项。
- “资源条”面板保留启用、数值显示、锚点、侧边、X/Y 偏移、间距及仅战斗显示选项。
- “经验槽”面板保留启用及任务经验值百分比选项。

每个面板标题使用“玩家 > 面板名称”，不再显示与面板名称重复的分组标题。所有选项设置为强制换行，因此每行只显示一个选项。

## 行为与数据

本次只调整设置界面的菜单和布局，不改变任何设置键、SavedVariables、默认值、回调或游戏内功能。现有主开关依赖、子选项禁用状态、配置切换刷新、能量条同步及数值显示刷新逻辑继续生效。

五个面板共用现有的选项克隆、依赖解析和刷新能力，但分别维护自己的控件列表。面板显示时只刷新当前面板，同时保留全局配置切换后对相关状态的同步。

## 兼容与失败处理

仍以 GW2_UI 提供的玩家综合、职业资源和施法条原始选项作为来源。任一必需来源面板或选项缺失时，不创建这组自定义面板，避免注册不完整菜单或产生 Lua 错误。原生页面的隐藏规则保持不变。

## 验收标准

1. “框体 > 玩家”下显示 5 个新菜单，顺序为血球和贴图、施法条、能量条、资源条、经验槽。
2. “状态条”菜单不再显示。
3. 原“状态条”内所有选项均且仅出现在对应的新面板。
4. 每个新面板内的选项均独占一整行，页面内无重复分组标题。
5. 所有设置值、默认值、回调、依赖禁用和配置切换行为与拆分前一致。
6. 现有综合、渐隐、增益光环和减益光环页面不受影响。
7. 自动回归测试覆盖菜单注册、旧入口移除、选项归属和单行布局；全部既有测试继续通过。
