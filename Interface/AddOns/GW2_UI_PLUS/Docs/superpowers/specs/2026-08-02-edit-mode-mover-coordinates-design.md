# 编辑模式移动坐标设计

## 目标

在 HUD 编辑模式选中可移动组件后，于选项面板的“移动”标题后显示该组件当前的 X、Y 坐标，例如 `移动  X: 120  Y: -35`，方便精确记录和调整位置。

## 坐标定义

坐标直接读取当前移动器 `GetPoint()` 返回的 X、Y 偏移量，即组件相对当前 `UIParent` 锚点的偏移。显示值按 GW2_UI 保存位置时的规则四舍五入为整数。

## 显示行为

- 选中组件后立即显示坐标。
- 鼠标拖拽组件期间最多每 0.1 秒刷新一次。
- 使用上下左右按钮微调、恢复默认或结束拖拽后立即显示最新坐标。
- 未选中组件时不执行额外操作，完全保留 GW2_UI 原有标题和面板行为。
- 无法取得有效坐标时不追加坐标文本，避免错误内容或 Lua 报错。

## 实现边界

增强逻辑放在 GW2_UI_PLUS 现有 HUD 编辑界面运行时补丁中，不修改依赖插件 GW2_UI。复用现有“移动”标题 FontString，不新增面板控件、配置项或持久化数据。

刷新逻辑只在编辑面板显示、存在已选中移动器且坐标发生变化时更新文本。持续刷新采用 0.1 秒节流，避免逐帧字符串格式化。

## 验证

回归检查覆盖：选中组件后显示整数坐标、坐标变化后刷新、未选中时不改写原有标题、无效坐标时安全退出，以及现有动作条移动器检查继续通过。
