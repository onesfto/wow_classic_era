# 聊天设置分类设计

## 目标

将“Plus > 聊天”现有的“综合”“频道按钮”“聊天窗口”三个页面按用户任务重新整理为四个同级菜单，消除重复入口，并让每个设置只出现在一个语义明确的位置。

本次只调整设置界面的菜单、分组、顺序和必要的显示名称，不改变设置键、SavedVariables、默认值、回调或游戏内行为。

## 菜单结构

“聊天”标签按以下顺序显示：

1. 聊天增强
2. 窗口布局
3. 频道按钮
4. 消息管理

不再显示“综合”和“聊天窗口”菜单。“聊天按钮位置”只保留在“窗口布局”，不再提供重复入口。

## 聊天增强

该页面收纳聊天框的基础能力、消息显示增强和直接交互功能：

- 启用 GW2 聊天框
- GW2 消息样式
- URL 链接
- 鼠标悬停显示链接提示
- 缩短频道名称
- 队伍职责图标
- 提及时使用职业颜色
- 发言人名字使用职业颜色
- 聊天表情
- 快速加入消息（仅在原设置可见的平台显示）
- 复制聊天行

页面保留 GW2 聊天框主开关对原生子选项的依赖关系。“发言人名字使用职业颜色”继续使用 GW2_UI_PLUS 自己的设置和即时刷新逻辑，不错误地挂到 GW2 聊天框主开关下。

## 窗口布局

该页面只负责主聊天窗口的几何布局、输入区域、控制按钮和滚动行为。

### 位置与大小

- 固定位置与大小
- 宽度
- 高度
- 左边距
- 下边距
- 恢复默认位置与大小

以上子项继续受“固定位置与大小”控制；关闭后位置和尺寸交还给暴雪默认行为。

### 外观与操作

- 闲置时渐隐
- 未输入时隐藏输入栏
- 输入栏移到顶部
- 聊天按钮位置

“聊天按钮位置”沿用 GW2_UI 的 `CHAT_BUTTONS_POSITION`，只在本页面提供一个入口。

### 滚动

- 每次滚动消息数量
- 自动滚到底部的等待时间

## 频道按钮

保留频道按钮条作为独立页面，但重新整理内部顺序和分组。

### 基本设置

- 启用频道按钮条
- 鼠标离开渐隐
- 动态显隐

### 位置与外观

- 附着位置
- X 偏移
- Y 偏移
- 缩放
- 重置位置与缩放

### 聊天频道

- 频道屏蔽控制窗口
- 说、喊、会、队、团、战
- 综合、交易、组队、PIG、大脚世界

### 快捷功能

- 表情
- Roll
- 宏命令

### 插件入口

- DBM 测距
- AtlasLoot
- 表格
- 集结号
- MRT 团队检查

插件入口继续只在对应插件已加载时显示。所有频道和按钮开关继续受频道按钮条主开关控制。

## 消息管理

该页面统一收纳聊天记录、时间戳、提醒、输入保护和消息过滤。

### 记录与时间

- 保存聊天历史
- 历史记录数量
- 清空历史
- 复制窗口最大行数
- 所有消息添加时间戳
- 时间戳格式

### 关键词与通报

- 高亮关键词
- 关键词高亮颜色
- 关键词提醒声音
- 打断通报频道

原“关键词”显示名称明确为“高亮关键词”，用于和黑名单输入框区分。原平台或客户端隐藏条件保持不变。

### 过滤与保护

- 相同消息过滤间隔
- 战斗中重复字符限制
- 不显示进入/离开频道信息
- 重复符号、词、句裁减
- 启用关键词黑名单
- 黑名单关键词
- 不显示“界面错误太多”提示

原黑名单输入框显示名称明确为“黑名单关键词”。黑名单开关与输入框的依赖关系保持不变。

## 实现边界

四个页面使用现有选项描述、设置键和回调构建，不复制业务逻辑。来自 GW2_UI 原生聊天面板的选项在新页面中继续读写 `GW.settings`，来自 GW2_UI_PLUS 的选项继续读写各自现有数据库。

页面显示、关闭和配置切换时继续使用项目现有的设置控件注册、依赖解析与刷新机制。任一必需来源面板或构建能力缺失时，不注册不完整的聊天标签，避免空页面或 Lua 报错。

## 验收标准

1. “Plus > 聊天”依次显示“聊天增强”“窗口布局”“频道按钮”“消息管理”四个菜单。
2. 不再显示“综合”和“聊天窗口”菜单。
3. 本设计列出的所有现有聊天设置均且仅出现在指定页面，隐藏条件不变。
4. “聊天按钮位置”只出现在“窗口布局”，修改后仍立即调用 GW2_UI 的位置刷新逻辑。
5. “高亮关键词”和“黑名单关键词”名称明确，分别读写原有的高亮词与黑名单数据。
6. 所有设置键、SavedVariables、默认值、回调、重载提示和依赖禁用行为与拆分前一致。
7. 频道按钮页面按“基本设置、位置与外观、聊天频道、快捷功能、插件入口”分组，插件入口继续按加载状态显示。
8. 自动回归测试覆盖菜单顺序、旧入口移除、选项唯一归属、重复入口移除和关键依赖；全部既有测试继续通过。
