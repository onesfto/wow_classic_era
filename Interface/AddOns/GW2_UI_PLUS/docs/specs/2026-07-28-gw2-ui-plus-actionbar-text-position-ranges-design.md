# GW2 UI Plus 动作条文字位置与尺寸范围设计

> 本文档随 GW2 UI Plus 插件保存。

## 目标

在不修改 GW2 UI 源码的前提下，统一 GW2 UI Plus 顶级“动作条”设置中的命名、尺寸和间距范围，并为主动作条及动作条 2–8 提供一致、可预测的快捷键与宏名称定位能力。

## 设置命名与范围

- 所有设置界面中的“列数”改名为“行按钮数”，内部存档字段继续使用现有 `Columns`，不迁移或复制数据。
- 所有已有的按钮间距滑块范围统一为 `0–20`。
- 所有按钮尺寸滑块范围统一为 `12–64`。
- 法师动作条不新增间距、快捷键或宏名称设置。
- 宠物动作条新增“尺寸”滑块。

## 按钮尺寸默认值

- 主动作条默认尺寸为 `48`。
- 动作条 2–8、姿态条、宠物动作条和法师动作条默认尺寸均为 `36`。
- 每个页面的“恢复默认”按钮必须同步恢复对应尺寸。
- 旧存档中已有的尺寸继续保留；只有缺少字段或用户点击“恢复默认”时才采用新默认值。

## 文字位置模型

快捷键和宏名称共用同一个文字定位器，支持以下七个位置：

- 左上：`TOPLEFT`
- 上：`TOP`
- 右上：`TOPRIGHT`
- 居中：`CENTER`
- 左下：`BOTTOMLEFT`
- 下：`BOTTOM`
- 右下：`BOTTOMRIGHT`

位置决定文字区域的基准锚点。`X=0、Y=0` 表示所选锚点的准确位置，偏移直接从该点计算，不叠加 GW2 UI 原生隐藏偏移。

文字水平对齐规则：

- 左上、左下：左对齐。
- 上、居中、下：居中对齐。
- 右上、右下：右对齐。

GW2 UI 刷新按键绑定、按钮样式或宏名称后，Plus 必须重新应用位置、对齐、偏移与字体大小，避免原生刷新覆盖设置。

## 主动作条

主动作条新增完整的快捷键设置：

- 显示快捷键。
- 位置。
- 字体大小。
- X 偏移。
- Y 偏移。

快捷键默认值：

- 位置：“下”。
- X/Y 偏移：`0,0`。
- 字体大小：`12`。

主动作条宏名称保留显示、字体大小及 X/Y 偏移，并新增位置下拉框。

宏名称默认值：

- 位置：“上”。
- X/Y 偏移：`0,0`。
- 字体大小：`12`。

## 动作条 2–8

快捷键设置继续按每条动作条独立保存，并将默认位置改为“左上”。

宏名称增加独立位置字段，默认位置为“下”。每条动作条分别保存：

- 显示状态。
- 位置。
- 字体大小。
- X/Y 偏移。

旧存档已有快捷键位置时继续保留；缺少位置字段或点击“恢复默认”时，快捷键恢复为“左上”、宏名称恢复为“下”。

## 姿态条与宠物动作条

- 快捷键默认位置继续使用“右上”。
- 不增加宏名称设置。
- 姿态条尺寸范围改为 `12–64`，默认 `36`。
- 宠物动作条新增独立尺寸字段，范围 `12–64`，默认 `36`。
- 宠物动作条的按钮布局、父框体尺寸与按钮间距均使用新的宠物按钮尺寸重新计算。
- 宠物头像、血量等单位框体不受宠物动作按钮尺寸设置影响。

## 法师动作条

- 尺寸范围改为 `12–64`，默认 `36`。
- 不增加间距、快捷键或宏名称设置。
- 现有显示、排列方向与技能分组功能保持不变。

## 设置界面布局

- 所有“列数”标签显示为“行按钮数”。
- 快捷键与宏名称分组采用相同顺序：
  1. 显示开关单独一行。
  2. 位置与字体大小同一行。
  3. X 偏移与 Y 偏移同一行。
- 每行最多放置两个滑块或一个下拉框加一个滑块。
- “恢复默认”同时刷新实际动作条、顶级设置页和 HUD 编辑面板中的对应值。

## 存档兼容

新增字段保存在 `GW2_UI_PLUS_ActionBarSV`：

- `mainBarHotkeyPosition`
- `mainBarHotkeyX`
- `mainBarHotkeyY`
- `mainBarHotkeySize`
- `mainBarShowHotkey`
- `mainBarMacroPosition`
- `bar2MacroPosition`～`bar8MacroPosition`
- `petBarSize`

现有字段继续原地复用。初始化只补齐缺失字段，不覆盖已有用户设置。

## 战斗保护

所有涉及受保护动作按钮的尺寸、布局、显示和文字位置变化，在战斗中只记录最终配置，不直接触碰受保护框体；脱战后一次应用最终状态。

## 验证

- Lua 语法检查与现有动作条测试全部通过。
- 验证所有设置页只显示“行按钮数”，不再显示“列数”。
- 验证尺寸滑块范围均为 `12–64`，默认值主动作条为 `48`，其余动作条为 `36`。
- 验证所有已有间距滑块范围为 `0–20`，法师动作条不出现间距。
- 验证宠物动作条尺寸改变后按钮和布局同步变化，宠物单位框体不受影响。
- 验证主动作条快捷键默认“下”、宏名称默认“上”。
- 验证动作条 2–8 快捷键默认“左上”、宏名称默认“下”。
- 验证七个位置在 `0,0` 时准确落到对应锚点，水平对齐正确。
- 验证正负 X/Y 偏移从当前锚点计算。
- 验证按键绑定和 GW2 UI 按钮刷新后，文字位置不会被覆盖。
- 验证“恢复默认”同时更新存档、设置界面、HUD 编辑面板和实际动作条。
- 验证战斗中修改只排队，脱战后只应用最终配置。
