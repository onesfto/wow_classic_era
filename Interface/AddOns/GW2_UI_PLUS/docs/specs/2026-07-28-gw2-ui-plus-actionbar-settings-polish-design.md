# GW2 UI Plus 动作条设置排版与法师条修复设计

> 本文档随 GW2 UI Plus 插件保存。

## 目标

在不修改 GW2 UI 源码的前提下，统一 Plus 顶级“动作条”设置页的标题间距、分栏和恢复按钮样式，
补齐动作条文字大小设置，并修复经典旧世法师动作条按钮不能施法的问题。

## 设置页排版

- 分组标题使用原生标题高度，标题与第一行选项之间保留 8 像素间距。
- 扩展 Plus 设置渲染器，使复选框可声明 2、4、5 列；滑块每行最多两项。
- “恢复默认”使用附加组件设置页相同的整行负向按钮。
- 多动作条中的名称简化为“按钮数、列数、尺寸、间距”：
  - 按钮数与列数一行。
  - 尺寸与间距一行。
  - 快捷键的 X 偏移、Y 偏移一行，字体大小单独下一行。
  - 宏名称的 X 偏移、Y 偏移一行，字体大小单独下一行。
- 姿态条和宠物动作条增加快捷键字体大小，范围 8–48。
- 主动作条增加宏名称的显示开关、X/Y 偏移和字体大小。
- “使用球状血条样式”和“为血球预留中间空隙”放在“血球与施法条”下的同一行。

## 法师动作条

- “显示法师动作条”和“竖向排列”同一行。
- 传送、传送门、造食物、造水、魔法宝石五个开关同一行。
- 默认只对法师启用：法师默认开启动作条，非 法师默认关闭且整个页面不可操作。
- 默认横向排列；传送与传送门开启；造食物、造水、魔法宝石关闭。
- 安全按钮同时注册 `AnyUp` 与 `AnyDown`，适配 `ActionButtonUseKeyDown`，确保点击能施法。

## 文字与默认值

- 快捷键字体和宏名称字体范围均为 8–48。
- 新存档字段从按钮当前字体大小初始化，无法读取时使用 12。
- 恢复默认同时恢复偏移和字体大小。
- HUD 编辑界面的英文 `Layouts`、`Hide placeholders`、`Show placeholders`、`Show grid`、
  `Hide grid`、`Lock HUD` 由 Plus 在运行时翻译，不修改 GW2 UI 文件。

## 验证

- 先以测试证明旧代码不支持通用分栏、文字字号、职业限制和双点击事件。
- 验证主条、多动作条、姿态条、宠物条文字位置与字号应用。
- 验证所有动作条页面标题间距与恢复按钮整行样式。
- 验证非 法师页面可见但不可点击，法师默认值正确。
- Lua 语法检查和 Plus 全部测试通过。
