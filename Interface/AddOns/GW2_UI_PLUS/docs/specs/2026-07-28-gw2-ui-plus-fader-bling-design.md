# GW2 UI Plus 全局渐隐 Bling 优化设计

> 本文档随 GW2 UI Plus 插件保存。

## 背景

开启全局渐隐后，参与渐隐的动作条越多，换装导致血量大幅变化时越卡。隔离测试表明，
成本与半透明动作条数量正相关，并非生命值事件或渐隐状态机重复触发。

NDui_Plus 与 ElvUI 都使用统一的渐隐父框体，同时在淡出时额外关闭动作按钮的冷却完成
闪光（Bling），避免动作条处于低 alpha 时仍渲染闪光层。GW2 UI 原生仅在动作条自身
隐藏时关闭 Bling；Plus 通过父框体实现半透明，因此绕过了原生处理。

## 方案

在 `ActionBar/Fader.lua` 增加统一的 Bling 状态同步：

- 淡出目标 alpha 小于或等于 0.5 时，对所有实际参与渐隐的按钮调用
  `cooldown:SetDrawBling(false)`。
- 淡入全亮时恢复 `cooldown:SetDrawBling(true)`。
- 透明度大于 0.5 时保留 Bling，与 NDui/ElvUI 的阈值一致。
- 只遍历已勾选且当前由渐隐父框体接管的动作条。
- 覆盖主动作条、多动作条、姿态条、宠物动作条和法师动作条。
- 不改变冷却转圈、冷却数字、按钮点击、鼠标渐隐及保持全亮条件。
- 关闭全局渐隐或交还动作条时必须恢复 Bling，避免配置切换后残留。

## 验证

- 回归测试验证 alpha 0.5 淡出时关闭 Bling。
- 回归测试验证 alpha 大于 0.5 时不关闭 Bling。
- 回归测试验证淡入和关闭全局渐隐时恢复 Bling。
- Lua 语法检查通过。
- 游戏内使用 0.5 alpha、全选动作条，复测“脱光→穿上”场景。
