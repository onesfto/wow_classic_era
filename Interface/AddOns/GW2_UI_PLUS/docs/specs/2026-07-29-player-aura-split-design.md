# GW2_UI_PLUS 玩家光环拆分设计

## 目标

把“框体 → 玩家 → 光环”拆成两个子页面：

- 增益光环
- 减益光环

两个页面各有独立开关。关闭开关时只隐藏对应的 GW2_UI 光环框，不恢复暴雪原生光环，也不影响另一类光环。

## 范围约束

- 只修改 `GW2_UI_PLUS`。
- 不修改 `GW2_UI` 本体目录中的任何文件。
- 继续复用 GW2_UI 原生的光环配置值、设置项、控件和回调。
- 不复制增益、减益的排序、尺寸、间距和动画配置逻辑。
- 不改变现有光环配置值或默认布局。

## 菜单与页面

玩家子菜单调整为：

1. 综合
2. 资源条
3. 增益光环
4. 减益光环

GW2_UI 原生只提供一个 `player_aura` 页面。GW2_UI_PLUS 缓存该页面的完整数据源，并基于原生设置项的 `groupHeaderName` 建立两个过滤视图：

- 增益视图包含独立增益开关以及 `Buffs` 分组的原生设置项。
- 减益视图包含独立减益开关以及 `Debuffs` 分组的原生设置项。

两个菜单项共用原生页面框体，但每次选择时都会切换到对应的数据源，并更新面包屑和说明文字。离开“框体”标签时恢复原生页面的完整数据源、标题和布局，保证 GW2_UI 原设置入口仍然完整可用。

## 独立开关与保存

在 `GW2_UI_PLUS_SV` 中保存两个布尔值：

- `playerBuffAurasEnabled`
- `playerDebuffAurasEnabled`

首次初始化时，两者都继承 GW2_UI 当前的 `PLAYER_BUFFS_ENABLED`，避免升级后改变现有显示状态。

两个页面各加入一个名为“启用”的主开关：

- 增益开关只控制 `GW2UIPlayerBuffs`。
- 减益开关只控制 `GW2UIPlayerDebuffs`。

对应页面的原生设置项依赖各自的 PLUS 开关；关闭后设置项显示为不可用，重新开启后恢复。

## 运行时行为

GW2_UI 的 `PLAYER_BUFFS_ENABLED` 仍作为创建 GW2 光环系统的底层总入口，但不再直接出现在拆分后的两个视图中。

- 当底层总开关已开启且光环框已经创建时，独立开关即时显示或隐藏对应框。
- 当底层总开关关闭时，首次开启任意独立开关会把 `PLAYER_BUFFS_ENABLED` 设为开启，并显示现有的重载确认框；重载后 GW2_UI 创建两个光环框，PLUS 再按独立保存值隐藏不需要的一类。
- 两个独立开关都关闭时，底层总开关保持开启，两个 GW2 光环框都被隐藏，不恢复暴雪原生光环。
- 关闭某一类不会清除其排序、尺寸、位置或其他原生配置。

GW2 光环框基于受保护的光环头。非战斗状态下直接应用显隐；战斗中只保存新状态并等待 `PLAYER_REGEN_ENABLED`，脱离战斗后自动应用，避免受保护操作失败。

在玩家进入世界以及光环框可用后执行一次同步，确保重载、登录和切换角色后保存状态正确生效。

## 代码边界

- `MainMenu/MainMenu.lua`
  - 将玩家光环菜单拆成两个菜单项。
  - 构建并切换增益、减益过滤数据源。
  - 创建两个独立设置开关。
  - 在退出框体标签时恢复原生光环页面。
- 新增一个位于 `GW2_UI_PLUS/MainMenu` 下的光环控制模块：
  - 初始化两个保存值。
  - 分别控制两个 GW2 光环框的显隐。
  - 处理底层总开关和重载要求。
  - 在战斗中延迟应用。
- `GW2_UI_PLUS.toc`
  - 在 `MainMenu/MainMenu.lua` 之前加载光环控制模块。
- `tests`
  - 增加静态结构测试，验证菜单拆分、独立保存键、两个框体映射、战斗延迟逻辑以及没有修改 GW2_UI 本体。

## 异常与兼容处理

- 原生 `player_aura` 页面不存在时，不创建不完整的两个菜单入口，并沿用现有缺页提示。
- 某个 GW2 光环框尚未创建时保留保存值；光环框可用后再次同步。
- 重复打开设置窗口或重复准备页面时使用幂等标记，避免重复添加开关或重复过滤数据源。
- 不更改已有 SavedVariables 名称，只在现有 `GW2_UI_PLUS_SV` 表中增加字段。

## 验收标准

1. “框体 → 玩家”下显示“增益光环”和“减益光环”，不再显示“光环”。
2. 增益页面只显示增益开关和原生增益设置；减益页面只显示减益开关和原生减益设置。
3. 关闭增益只隐藏 `GW2UIPlayerBuffs`，减益仍显示。
4. 关闭减益只隐藏 `GW2UIPlayerDebuffs`，增益仍显示。
5. 两者都关闭时两个 GW2 光环框都隐藏，暴雪原生光环不恢复。
6. 重载和重新登录后独立显示状态保持不变。
7. 战斗中更改开关不会产生受保护操作错误，脱战后自动应用。
8. 排序、方向、每行数量、间距、尺寸、比例和动画等原生设置继续生效。
9. 离开“框体”标签后，GW2_UI 原生光环页面仍显示完整内容。
10. 本功能没有修改 `GW2_UI` 本体目录中的任何文件。
