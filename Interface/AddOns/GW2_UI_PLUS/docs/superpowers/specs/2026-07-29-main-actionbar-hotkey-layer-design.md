# 主动作条快捷键绘制层级修复设计

## 目标

在不修改 GW2_UI 原生插件的前提下，修复主动作条快捷键文字被快捷键黑色背景遮盖的问题。

## 范围

- 仅修改 GW2_UI_PLUS。
- 仅处理主动作条中同时具有 `HotKey` 与 `hkBg` 的按钮。
- 保留现有黑色快捷键背景及其位置、尺寸、透明度和显隐逻辑。
- 不改变其他动作条、宏名称或按钮图标的绘制层级。

## 方案

GW2_UI_PLUS 当前通过代理 `FontString` 显示快捷键，并把主动作条的 `hkBg` 背景锚到该代理文字。修复时，在确认按钮存在 `hkBg` 且当前代理对应 `button.HotKey` 后，显式把代理文字设为 `OVERLAY` 的高子层级，使其稳定绘制在背景之上。

背景继续使用 GW2_UI 创建的原生对象，GW2_UI 源码与资源均不修改。

## 验证

- 先补充回归测试，验证带 `hkBg` 的主动作条快捷键代理被设置到预期绘制层级；测试在实现前应失败。
- 验证不带 `hkBg` 的其他动作条代理不执行主动作条专用层级调整。
- 运行现有动作条测试与 Lua 语法检查。
- 检查最终差异只包含 GW2_UI_PLUS 内与本问题直接相关的文件。
