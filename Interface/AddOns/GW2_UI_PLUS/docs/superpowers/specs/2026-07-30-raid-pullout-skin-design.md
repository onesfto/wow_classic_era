# 拖出职业团队窗口皮肤设计

## 目标

美化从团队页面右侧职业按钮拖出的原生团队窗口，同时保留暴雪原有的生成、拖动、关闭和成员更新功能。

## 已确认视觉

- 窗口宽度调整为原生宽度的 1.5 倍。
- 外层使用 GW2_UI 的 `DefaultWithSmallBorder` 背景。
- 职业标题保留在窗口顶部并居中显示。
- 每个成员的血条和法力条横向铺满窗口内容区。
- 成员名字居中覆盖在血条上。
- 状态条材质与颜色直接复用 GW2_UI 的现有资源和原生单位状态颜色，不新增自定义颜色体系。

## 实现边界

- 只处理 `Blizzard_RaidUI` 创建的 `RaidPullout` 窗口和其中的成员按钮。
- 通过暴雪现有的拉出窗口创建、获取和更新入口追加幂等皮肤。
- 不替换原生数据更新逻辑，不创建另一套团队框架。
- 不修改 8 小队布局、右侧职业按钮皮肤或团队信息弹窗。

## 验收标准

1. 新拖出的职业窗口使用 PLUS 小边框，宽度为原生的 1.5 倍。
2. 已存在的拉出窗口也能被皮肤处理。
3. 成员血条和法力条占满可用宽度，名字居中位于血条之上。
4. 生命值、法力值、职业颜色、成员增减和关闭行为继续由原生逻辑驱动。
5. 皮肤重复执行不会重复创建背景或破坏脚本。
6. 社交页面专项测试、Lua 语法检查和差异检查通过。
