# SimpleRaidTargetIcons 轻量皮肤设计

## 目标

为 `/srti` 打开的 SimpleRaidTargetIcons 设置窗口应用 GW2_UI 材质与默认字体，同时保留原布局、角色模型和全部设置功能。

## 范围

- 主窗口、选项区、测试区、四个设置分组框和可选的第三方插件区使用 GW2 背景材质。
- 设置窗口内文字使用 `UNIT_NAME_FONT`，保留原字号、样式、颜色及启用或禁用状态。
- 复选框和三个滑块使用对应的 GW2 控件材质。
- 两个按键按钮使用 GW2 普通按钮材质。
- 两个清除绑定按钮和右上角关闭按钮使用 GW2 关闭按钮材质。

## 非目标

- 不改变任何控件的尺寸、锚点或布局。
- 不改变测试区的角色模型、团队标记图标和测试交互。
- 不处理标记圆盘、标记条、鼠标图标及按键捕获弹窗。
- 不修改 SimpleRaidTargetIcons 插件源文件。

## 实现方案

新增独立皮肤文件 `skins/SimpleRaidTargetIcons.lua`，通过现有皮肤内核注册到 `SimpleRaidTargetIcons`。

目标插件在自己的 `ADDON_LOADED` 处理中首次调用 `SRTI:Options()` 创建设置窗口，随后把该方法替换为显示或隐藏窗口的切换函数。皮肤注册后安全钩住当时的 `SRTI.Options`，使首次动态创建完成后立即应用皮肤；若窗口已经存在，则立即补做处理。

皮肤只处理 `SRTI.menu` 暴露的已知设置控件。背景框、复选框、滑块和按钮按字段精确获取，不递归修改所有框体，避免误处理角色模型及其他功能窗口。

皮肤入口使用幂等标记，确保重复输入 `/srti` 不会重复创建背景或重复美化控件。

## 字体策略

递归读取设置窗口内已有 `FontString` 的当前字号与样式，仅将字体文件替换为 `UNIT_NAME_FONT`。

SimpleRaidTargetIcons 会在设置状态变化时通过 `SetFontObject` 切换部分文字的启用与禁用字体。皮肤为已发现的文字安全钩住 `SetFontObject`，在原字体对象更新后再次只替换字体路径，从而保留新字号、颜色和禁用状态。

## 验证

- 验证皮肤注册目标为 `SimpleRaidTargetIcons`。
- 验证设置窗口动态创建后应用背景、复选框、滑块和按钮材质。
- 验证角色模型与无关按钮不会被误处理。
- 验证字体路径被替换，而字号与样式保持不变。
- 验证后续调用 `SetFontObject` 后仍使用 GW2 默认字体。
- 验证重复执行皮肤不会重复处理。
- 运行现有 Lua 测试，确认没有影响其他皮肤。
