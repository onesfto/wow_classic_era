# GW2_UI_PLUS 工具条设计

## 目标

在 GW2_UI 设置窗口的“附加组件”分类下新增“工具条”子页，并在其中提供四个独立功能组：

```text
工具条
├── 队伍管理
├── 快捷条
├── 标记条
└── 性能条
```

四个功能均由 GW2_UI_PLUS 独立实现或接管，不调用 PIG 的内部函数，也不修改 PIG 源码。PIG 被禁用或卸载后，这些功能仍须正常工作。

## 范围

### 包含

- 接管 GW2_UI 现有队伍管理按钮和面板的显示、缩放、默认位置及编辑界面注册。
- 参考 PIG 行为，在 GW2_UI_PLUS 内独立实现快捷条、标记条和性能条。
- 四个功能分别注册为 GW2_UI 编辑界面的独立移动框。
- 在“附加组件 → 工具条”中提供四个同名设置分组。
- 使用 GW2_UI_PLUS 自己的存档保存启用状态、尺寸及功能选项。
- 使用 GW2_UI 的配置存档保存四个移动框的位置，以符合 `GW.RegisterMovableFrame` 的要求。

### 不包含

- 不复制 PIG 的界面代码、全局变量或设置面板。
- 不修改 PIG 的存档开关，也不自动关闭 PIG 对应功能。
- 不提供独立拖动柄或“锁定位置”选项；位置统一由 GW2_UI 编辑界面管理。
- 不提供背景样式、颜色或透明度设置。
- 不实现 PIG 的战斗记录按钮。
- 不实现大灾变及以上版本才支持的地面标记条。
- 不为性能条提供缩放。

## 默认状态

- 队伍管理：默认启用。
- 快捷条：默认关闭。
- 标记条：默认关闭。
- 性能条：默认关闭。

此默认值避免 PIG 仍启用时出现重复工具条，同时保留 GW2_UI 原有队伍管理能力。

## 架构

新增 `Toolbar` 目录，每个运行时模块只负责一个功能；公共模块负责存档、编辑界面注册和恢复默认位置。设置模块只负责构建 GW2_UI 设置页，不直接实现按钮行为。

建议文件职责：

- `Toolbar/Core.lua`：默认值、存档初始化、GW2_UI mover 默认位置注入、公共刷新与恢复默认逻辑。
- `Toolbar/GroupManage.lua`：接管 `GwManageGroupButton` 和 `GwGroupManage`，处理队伍可见性、缩放及 mover。
- `Toolbar/QuickBar.lua`：创建快捷条按钮、状态刷新、计时器和倒计时逻辑。
- `Toolbar/MarkerBar.lua`：创建经典旧世目标标记条并处理自动显隐。
- `Toolbar/PerformanceBar.lua`：创建 FPS、本地延迟、世界延迟信息条并处理尺寸更新。
- `Toolbar/Options.lua`：构建“附加组件 → 工具条”设置页。
- `tests/ToolbarSettings_test.lua`：验证菜单名称、分组、默认值和设置项范围。
- `tests/ToolbarRuntime_test.lua`：验证按钮清单、经典版本限制、显隐规则和 mover 注册。

`GW2_UI_PLUS.toc` 在 `core.lua` 之前加载运行时模块和设置模块；`core.lua` 将工具条设置页注册到“附加组件”分类。

## 编辑界面

四个功能分别调用 `GW.RegisterMovableFrame`，名称固定为：

- 队伍管理
- 快捷条
- 标记条
- 性能条

每个实际框体始终锚定到自己的 `gwMover`。设置页的“恢复默认”同时恢复模块选项和 mover 默认坐标。

编辑界面打开时，即使功能因当前状态隐藏，仍应显示对应 mover，方便单人状态下调整“队伍管理”位置。退出编辑界面后重新执行正常显隐规则。

缩放由设置页控制：

- 队伍管理、快捷条和标记条支持缩放。
- 性能条不支持缩放，改用宽度和高度控制。
- mover 的可视尺寸必须随实际框体缩放或宽高变化同步更新。

## 队伍管理

### 显示规则

- 只有处于小队或团队时才显示入口按钮。
- 单人时入口按钮和管理面板都隐藏。
- 进入队伍后显示入口；离开队伍后立即收起并隐藏。
- 编辑界面中显示 mover，但不强制显示可交互管理面板。

### 保留功能

- 展开和收起管理面板。
- 输入玩家姓名并邀请。
- 离开队伍或团队。
- 显示坦克、治疗和输出人数。
- 设置八种目标标记。
- 清除目标标记。
- 就位确认。
- 职责确认。
- 使用保存的默认秒数发起倒计时。
- `Ctrl + 左键`且 DBM 已加载时调用 DBM 倒计时。
- 小队转换为团队。
- 团队转换为小队。
- 根据队长或助理权限更新相关按钮状态。

### 设置

- 启用。
- 缩放。
- 恢复默认。

## 快捷条

### 按钮

快捷条按顺序提供八个可独立显示或隐藏的按钮：

1. 离开队伍：左键离开普通队伍；右键离开随机副本队伍。
2. 进出副本：根据随机副本状态传送进入或离开。
3. 队伍转换：小队转团队，团队转小队。
4. 重置副本：打开暴雪重置副本确认框。
5. 时间：显示当前时间、战斗计时或动态模式。
6. 职责确认。
7. 就位确认。
8. 倒计时：左键使用默认秒数，右键选择预设时长。

不创建战斗记录按钮。

### 时间功能

- 战斗计时模式。
- 当前时间模式。
- 动态模式：战斗时显示战斗计时，脱战后显示当前时间。
- 左键重置战斗计时。
- 右键打开暴雪时间管理入口。
- 提示中显示本次登录时长。
- 处于副本时显示本次进本时长。
- 支持暴雪的 12/24 小时制设置。
- 支持隐藏计时按钮自身背景。

### 倒计时功能

- 默认倒计时范围为 3～180 秒。
- 右键菜单提供 3、5、10、30、60、180、300、600 秒预设。
- 可启用最后五秒读秒音效。
- 可选择并试听读秒音效。
- 不实现 PIG 当前被禁用的倒计时结束音效。

### 设置

- 启用。
- 八个按钮分别显示或隐藏。
- 缩放。
- 时间模式。
- 12/24 小时制。
- 隐藏计时背景。
- 默认倒计时秒数。
- 读秒音效开关。
- 读秒声音选择与试听。
- 恢复默认。

## 标记条

### 功能

经典旧世只创建目标标记条：

- 星星
- 圆圈
- 菱形
- 三角
- 月亮
- 方块
- 十字
- 骷髅
- 清除标记

点击标记按钮对当前目标设置相应团队标记；清除按钮移除当前目标标记。

### 显示

- 启用后常驻显示。
- 没有目标或标记权限时保留工具条，但禁用并置灰按钮。
- 只有队伍管理按组队状态自动隐藏。

### 设置

- 启用。
- 缩放。
- 恢复默认。

## 性能条

### 内容

- FPS。
- 本地延迟。
- 世界延迟。

三项可独立显示或隐藏。FPS、延迟每 0.25 秒刷新一次；模块隐藏时停止刷新。

### 尺寸和布局

- 宽度控制性能条总宽度。
- 高度控制背景和文字区域高度。
- 当前启用的项目在总宽度内等宽排列。
- 至少保留一个项目；用户试图关闭最后一项时拒绝该操作并恢复勾选状态。
- 宽度和高度变化后立即更新实际框体、文字布局及 mover 尺寸。

### 设置

- 启用。
- 显示 FPS。
- 显示本地延迟。
- 显示世界延迟。
- 宽度。
- 高度。
- 恢复默认。

## 存档

在 `GW2_UI_PLUS_SV` 下新增独立的 `Toolbar` 表，保存：

- 四个模块的启用状态。
- 队伍管理、快捷条和标记条的缩放值。
- 快捷条按钮显隐、时间模式和倒计时设置。
- 性能条项目显隐、宽度和高度。

四个 mover 的位置使用独立的 `GW.settings` 键，不与 PIG 或 GW2_UI 现有 mover 共用。

读取存档时逐字段补默认值，不用整表覆盖，确保后续升级新增字段时保留用户现有配置。

## 状态与错误处理

- 所有队伍管理操作调用暴雪 API 前检查当前队伍状态和权限。
- 不支持的副本传送状态将禁用按钮并更新提示，而不是抛出错误。
- 战斗中不能安全执行的框体变化延迟到 `PLAYER_REGEN_ENABLED`。
- 标记条没有目标或权限时禁用不可用按钮，但不隐藏工具条。
- DBM 未加载时，队伍管理倒计时使用暴雪 API。
- PIG 同时启用时不读写其设置；允许用户自行决定关闭哪一套功能。

## 测试与验收

### 静态测试

- “附加组件”分类注册“工具条”子页。
- 页面名称严格为“队伍管理”“快捷条”“标记条”“性能条”。
- 默认只有队伍管理启用。
- 快捷条不存在战斗记录按钮和对应设置。
- 四个模块不存在锁定选项。
- 性能条不存在缩放选项，存在宽度和高度选项。
- 标记条在经典旧世不创建地面标记。
- 四个模块均调用 `GW.RegisterMovableFrame`。

### 游戏内验收

- 单人时队伍管理不可见；进入小队后出现；离队后立即隐藏。
- 编辑界面中能看到并分别移动四个 mover。
- 保存、取消、切换 GW2_UI 配置后位置行为正确。
- 三个可缩放模块缩放后 mover 尺寸正确。
- 性能条宽高变化后文字等宽排列且 mover 尺寸正确。
- 快捷条八个按钮行为和禁用状态正确。
- 时间三种模式、重置和12/24小时制正确。
- 倒计时默认值、右键预设和读秒音效正确。
- 标记条九个按钮正确，没有目标时仍显示且按钮置灰。
- PIG 禁用后四个模块不报错。
- PIG 同时启用时 GW2_UI_PLUS 不改写 PIG 存档。
