# 小地图插件悬浮按钮独立模块设计

## 目标

将 GW2_UI 的小地图插件按钮收纳功能拆到 GW2_UI_PLUS 中，使其完全由
GW2_UI_PLUS 的独立开关控制。无论 GW2_UI 小地图是否启用，插件悬浮按钮均按
GW2_UI_PLUS 的设置工作。

## 功能范围

- 在 GW2_UI_PLUS 的“附加组件”分类下增加“插件悬浮按钮”子页。
- 提供一个默认开启的主开关，状态保存在 `GW2_UI_PLUS_SV`。
- 开启时扫描小地图上的第三方插件按钮，将符合条件的按钮统一换肤并收纳到可展开的悬浮栏。
- 关闭时隐藏悬浮入口，并将已经收纳的按钮恢复到小地图。
- 后续加载的插件按钮也应被发现和收纳。
- 重复初始化不得创建多个悬浮入口。

## 独立性

- 不读取 `GW.settings.MINIMAP_ENABLED`。
- 不修改 GW2_UI 的小地图开关或相关保存值。
- 模块只依赖 GW2_UI 已加载的公共视觉能力和模板，因为 GW2_UI 是
  GW2_UI_PLUS 的必需依赖。
- 若 GW2_UI 已创建原生 `GwAddonToggle`，GW2_UI_PLUS 复用并接管该入口，
  避免出现两个悬浮按钮；入口最终是否显示只由 GW2_UI_PLUS 的独立开关决定。

## 模块结构

新增一个小地图插件按钮模块，负责：

1. 初始化保存值和事件监听。
2. 创建或接管悬浮入口。
3. 识别、换肤和收纳插件按钮。
4. 展开或收起按钮容器。
5. 关闭功能时解除位置锁定并恢复按钮。

设置页只负责读取和修改 GW2_UI_PLUS 保存值，并调用模块的启停接口，不直接处理
小地图按钮。

## 状态与数据流

首次加载时，模块将 `minimapAddonFlyoutEnabled` 初始化为 `true`。进入世界后：

- 开关为真：创建或接管入口，扫描按钮并更新悬浮栏。
- 开关为假：不收纳按钮，并确保入口隐藏、已有按钮被恢复。

修改开关后立即应用，不要求重新加载界面。插件后续加载时，模块延迟重新扫描，避免
遗漏较晚创建的小地图按钮。

## 关闭与恢复

模块在接管按钮前保存其父级、锚点、缩放、层级和层级类型。关闭功能时解除模块添加的
方法锁定，恢复这些属性，并清除模块自己的接管标记。模块不尝试还原第三方插件在被
接管期间主动修改但未生效的位置。

## 兼容与异常处理

- 忽略暴雪原生小地图控件、任务针点、采集标记和 GW2_UI 自身信息控件。
- 战斗或宠物对战期间需要调整受保护按钮时延后处理。
- 不符合按钮尺寸或对象类型要求的子对象保持不变。
- 缺少预期模板或视觉方法时安全退出，不影响其他 GW2_UI_PLUS 功能。

## 验证

自动化 Lua 测试覆盖：

- 保存值首次初始化为开启。
- 功能不读取 GW2_UI 小地图开关。
- 开启时创建或接管唯一入口并收纳符合条件的按钮。
- 关闭时隐藏入口并恢复按钮。
- 重复初始化不会创建第二个入口。
- 设置页提供独立主开关并调用模块启停接口。

游戏内验证覆盖 GW2_UI 小地图开启和关闭两种状态下的启用、展开、收起、关闭与
重新开启。
