# Myslot 主窗口轻量皮肤设计

## 目标

为 `/myslot` 打开的导入/导出主窗口及其导入进度窗口应用 GW2_UI 材质和默认字体，同时保留原布局与全部功能。

## 范围

- 主窗口使用 GW2 默认面板背景，并移除原生对话框标题材质。
- 主窗口内文字使用 `UNIT_NAME_FONT`，保留原字号、样式和语义颜色。
- 导入、导出、选项、关闭、配置管理及导入/导出选项箭头按钮使用 GW2 普通按钮材质。
- 导入/导出选项箭头保留原有箭头图标。
- 配置下拉框使用 GW2 下拉框材质。
- 导入/导出文本容器、滚动框、滚动条和编辑区使用 GW2 材质。
- 导入进度窗口使用 GW2 面板背景，进度条使用 GW2 状态条材质。

## 非目标

- 不改变任何控件的尺寸、锚点或布局。
- 不处理暴雪“选项 → 插件”中的 Myslot 设置页。
- 不处理导入/导出右键菜单、确认弹窗和配置命名弹窗。
- 不修改 Myslot 插件源文件。

## 实现方案

新增独立皮肤文件 `skins/Myslot.lua`，通过现有皮肤内核注册到 `Myslot`。

Myslot 主窗口在插件文件执行时创建，但文本编辑区及配置控件在插件自己的 `ADDON_LOADED` 回调中补充。皮肤注册后为 `MySlot.MainFrame` 安装 `OnShow` 后置脚本，在用户首次打开窗口时处理已完整创建的控件；若窗口当时已经显示，则立即补做处理。

主窗口没有公开多数控件字段。皮肤通过有限且明确的结构特征识别控件：

- 只将主窗口的直接 `Button` 子控件作为普通按钮处理，避免误改滚动条箭头。
- 通过经典下拉框的 `Button` 或左右中段字段识别配置下拉框。
- 通过包含 `ScrollFrame` 子控件的直接框体识别文本容器，再处理其滚动框、滚动条和编辑区。

导入进度窗口同样没有公开字段。皮肤仅在 `UIParent` 的直接子控件中查找尺寸为 `360 × 70`、层级为 `FULLSCREEN_DIALOG` 且包含 `StatusBar` 子控件的框体。全部特征同时满足后才应用皮肤，避免误处理其他窗口。

主窗口和进度窗口各自使用幂等标记，重复打开或多次导入不会重复套用皮肤。

## 字体策略

递归读取目标窗口内已有 `FontString` 和编辑区的当前字号与样式，仅将字体文件替换为 `UNIT_NAME_FONT`，不覆盖已有文字颜色。

## 验证

- 验证皮肤注册目标为 `Myslot`。
- 验证主窗口首次显示后应用背景、按钮、下拉框和文本区域材质。
- 验证箭头按钮的原有图标保持显示。
- 验证滚动条使用专用滚动条材质，不被普通按钮皮肤误处理。
- 验证字体路径被替换，而字号、样式和颜色保持不变。
- 验证只识别符合完整特征的导入进度窗口并替换状态条材质。
- 验证重复打开窗口不会重复处理。
- 运行现有 Lua 测试，确认没有影响其他皮肤。
