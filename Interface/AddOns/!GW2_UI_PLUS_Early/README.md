# !GW2_UI_PLUS_Early

**GW2 UI Plus (先行加载组件)**

这个组件是专门为了解决 [GW2_UI](https://www.curseforge.com/wow/addons/gw2-ui) 核心汉化失效问题而设计的。它必须与 GW2 UI 本体配合使用，且绝对不能被禁用或删除。

## 为什么需要这个插件？

在经典旧世版本中，`GW2_UI` 会在插件刚开始加载时（甚至早于大多数生命周期事件），就立刻将成百上千条界面词条锁定并构建好默认的英文界面。

因为常规的汉化插件（如 `GW2_UI_PLUS`）声明了对主插件的依赖（`Dependencies: GW2_UI`），这意味着它们只能在主插件加载完毕之后才能运行。等到汉化包启动时，界面词条已经被固定成了英文，此时再注册汉化往往已经无济于事。

## 工作原理

1. **强行优先加载**：插件名称前面的感叹号（`!`）可强制让魔兽世界客户端优先加载这个文件夹（根据字母排序机制）。
2. **提前注册字典**：它利用了加载时间差，在 `GW2_UI` 开始构建界面前，提前通过 `AceLocale-3.0` 往共享词典里“塞”满中文词条。
3. **保护词条不被覆盖**：当 `GW2_UI` 本体稍后加载并尝试写入它的英文默认词条时，它会发现词典中已经有了对应的值，所以放弃写入英文。最终使得整个插件深度中文化。

## 文件结构

- `!GW2_UI_PLUS_Early.toc` - 插件的目录和属性文件。
- `zhCN.lua` - 核心的预加载增量词典，包含了需要覆盖的全部中文汉化内容。
- `Libs/` - 内部自带的运行依赖库（`AceLocale-3.0`，`LibStub`），已针对阅读习惯进行了中文注释重构。
