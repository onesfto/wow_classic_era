## 详细迁移对照

### 1️⃣ 动作条 (Actionbar) - 🔄 部分迁移

**GW2_UI 原版功能**:
- ✅ 动作条总开关
- 🚫 自动布局管理（保留在本体）
- ⏸️ 空格子透明度
- ⏸️ 按钮标签显示
- ⏸️ 宏名称显示
- ⏸️ 按钮间距
- ⏸️ 距离指示器
- 🔄 主动作条显示模式（渐隐）
- 🔄 额外动作条 2-8（显示/隐藏）
- ⏸️ 姿态栏设置

**GW2_UI_PLUS 已迁移**:
- ✅ 全局渐隐系统（新增，比原版更强大）
  - 淡出透明度
  - 淡出延迟
  - 战斗中不渐隐
  - 有目标时不渐隐
  - 施法时不渐隐
  - 生命值不满时不渐隐
- ✅ 按钮尺寸调整（新增功能）
  - 主动作条尺寸
  - 动作条 2-8 尺寸
- ✅ 法师动作条（新增功能）
- ✅ 图腾栏（新增功能）

**待迁移功能**:
- ❌ 按钮间距独立控制
- ❌ 距离指示器样式
- ❌ 姿态栏独立设置

**迁移说明**:
- GW2_UI_PLUS 的动作条模块是**补充增强**，不是完全替代
- 原版的基础功能保留在 GW2_UI 本体
- PLUS 版本添加了全局渐隐、尺寸调整、职业专用条等新功能

### 3️⃣ 聊天 (Chat) - 🔄 部分迁移

**GW2_UI 原版功能** (27 个选项):

#### 已迁移到 GW2_UI_PLUS:
- ✅ 聊天窗口位置与尺寸 → `Modules/ChatWindow/`
  - 固定位置与大小
  - 宽度/高度
  - 左边距/下边距
- ✅ 玩家名职业颜色 → `Modules/ChatWindow/`
- ✅ 输入栏位置（顶部/底部）→ `Modules/ChatWindow/`
- ✅ 消息过滤功能 → `Modules/ChatWindow/`
  - 频道进出信息
  - 重复消息裁减
  - 关键词黑名单
- ✅ 频道按钮 → `Modules/ChatBar/`
  - 频道快速切换
  - 位置和缩放
  - 渐隐效果

#### 保留在 GW2_UI 本体:
- 🚫 聊天框架总开关
- 🚫 聊天字体
- 🚫 时间戳颜色
- 🚫 URL 链接检测
- 🚫 聊天淡出效果
- 🚫 输入框聚焦行为

**待迁移功能**:

## 📝 迁移指南

### 迁移前检查清单

- [ ] 确认功能在 GW2_UI 本体的位置
- [ ] 评估该功能是否适合迁移（是核心功能还是增强功能）
- [ ] 检查是否有第三方插件冲突
- [ ] 确定保存变量的命名规范

### 迁移步骤

1. **分析原始代码**
   - 阅读 GW2_UI 对应的 panel 文件
   - 理解功能逻辑和数据流
   - 记录所有设置选项

2. **设计新模块**
   - 确定模块名称和文件结构
   - 设计 SavedVariables 结构
   - 规划设置面板布局

3. **实现核心功能**
   - 创建模块核心文件
   - 实现功能逻辑
   - 添加错误处理

4. **创建设置面板**
   - 使用 GW2_UI 的设置 API
   - 添加选项控件
   - 实现依赖关系

5. **测试与优化**
   - 测试所有选项
   - 检查与本体的兼容性
   - 优化性能

6. **文档**
   - 更新本迁移清单
   - 编写模块 README
   - 添加代码注释
