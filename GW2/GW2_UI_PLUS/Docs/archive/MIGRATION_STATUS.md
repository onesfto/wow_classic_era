### 5️⃣ 冷却闪烁

```
原始来源: 无（全新开发）
迁移方式: 独立开发
改动程度: ⭐⭐⭐⭐⭐ (全新代码)
维护成本: ⭐⭐ (功能简单)
```

**功能特点**:
- 🆕 技能冷却完成时屏幕中央闪烁
- 🆕 完整的动画参数控制（9 个选项）
- 🆕 可移动的显示位置
- 🆕 支持显示技能名称

**实现方式**:
```lua
监听 SPELL_UPDATE_COOLDOWN 事件
  ↓
检测冷却从有 → 无的转换
  ↓
在屏幕中央播放闪烁动画
  ↓
淡入 → 停留 → 淡出
```

```
原始来源: 无（全新开发）
迁移方式: 独立开发
改动程度: ⭐⭐⭐⭐⭐ (全新代码)
维护成本: ⭐⭐ (功能简单)
```

**功能特点**:
- 🆕 收纳小地图周围的第三方插件按钮
- 🆕 8 个方向可选位置
- 🆕 不依赖 GW2_UI 小地图模块
- 🆕 自动识别插件按钮

**实现原理**:
```lua
扫描小地图周围的按钮
  ↓
识别第三方插件的按钮特征
  ↓
将按钮重新附着到悬浮入口
  ↓
点击入口展开/收起按钮列表
```

## 🎯 迁移原则

在整个迁移过程中，我们遵循以下原则：

1. **📦 模块化**: 每个功能独立成模块，降低耦合
2. **🔌 可插拔**: 所有模块可独立启用/禁用
3. **⚡ 性能优先**: 优化代码，降低资源占用
4. **🎨 风格统一**: 保持与 GW2_UI 视觉风格一致
5. **🔧 易维护**: 清晰的代码结构，充分的注释
6. **📚 文档完善**: 为每个模块提供详细文档
7. **🔄 向后兼容**: 尽可能保持与旧版的兼容性
