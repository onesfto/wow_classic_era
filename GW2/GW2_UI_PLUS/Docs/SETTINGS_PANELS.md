# GW2_UI_PLUS 设置面板清单

本文档记录设置窗口的页面结构和职责，不复制每个选项的完整默认值。实际选项以对应模块的 `Options.lua` 和游戏内页面为准。

## 顶层标签

| 标签 | 页面范围 | 主要来源 |
|---|---|---|
| 框体 | 玩家、目标、目标的目标、宠物 | `Modules/Settings/Settings.lua` |
| 聊天 | 聊天增强、窗口布局、频道按钮、消息管理 | `Modules/Settings/ChatTab.lua`、`ChatCategories.lua` |
| 队伍 | 小队、团队及团队子页面 | `Modules/Settings/PartyTab.lua` |
| 组件 | 通用、原生 HUD 页面和附加组件 | `Modules/Settings/ComponentsTab.lua`、`core.lua` |
| 编辑模式 | 直接进入 GW2_UI HUD mover | `Modules/Settings/EditModeTab.lua` |

## 框体

### 玩家

- 综合
- 血球和贴图
- 施法条
- 能量条
- 资源条
- 经验槽
- 渐隐
- 增益光环
- 减益光环

### 目标

- 综合
- 渐隐
- 增益光环
- 减益光环

### 目标的目标与宠物

两者都提供“综合”和“渐隐”页面。原生 GW2_UI 页面会根据当前客户端和已加载内容显示可用的其他设置。

## 聊天

聊天标签包含四个页面：

- **聊天增强**：GW2_UI 聊天样式、链接、复制、频道名称和职业颜色。
- **窗口布局**：主聊天窗口尺寸、位置、输入框和聊天按钮位置。
- **频道按钮**：频道按钮条的位置、缩放、显隐和插件入口。
- **消息管理**：历史数量、时间戳、关键词、重复消息和进出频道信息。

频道按钮命令为 `/gwcb`。

## 队伍

- **小队**：小队框体和小队相关设置。
- **团队**：团队总览、团队成员数量和团队子框体页面。

团队子页面的具体数量由当前 GW2_UI 原生页面决定，Plus 只负责重新组织入口和布局。

## 组件

组件页首项固定为“综合”，随后包含：

- **微型系统菜单**：原生 HUD 微型菜单相关设置。
- **微缩地图**：GW2_UI 小地图相关设置。
- **世界地图**：坐标、探索、兴趣点和地图增强设置。
- **一键换装**：alaGearMan 集成入口。
- **频道按钮**：频道按钮条设置。
- **冷却闪烁**：冷却完成提示图标和动画设置。
- **聊天窗口**：主聊天窗口布局和消息设置。
- **界面皮肤**：专业面板、邮件、任务日志和第三方皮肤开关。
- **插件收纳**：小地图周围插件按钮的收纳入口。
- **工具条**：快捷栏、队伍管理、标记条和性能条。

聊天标签会单独显示频道按钮和聊天窗口，不在组件页重复显示。

## 编辑模式

点击顶层“编辑模式”标签会直接打开 GW2_UI HUD 移动界面，不创建中间设置页面。战斗中不能移动受保护的界面元素。

## 设置实现约定

- 页面由 `core.lua` 和 `Modules/Settings/` 注册。
- 附加组件页面由模块的 `Build*Panel` 函数创建。
- 设置控件通过 `getter`、`setter`、`getDefault` 和可选 `callback` 连接到存档或 GW2_UI 配置。
- 复用原生控件时，必须把控件登记到当前页面的刷新列表。
- 页面布局规则统一记录在 [SETTINGS_LAYOUT_GUIDE.md](SETTINGS_LAYOUT_GUIDE.md)。

新增或移动页面后，只更新本文件的页面结构和职责；具体选项说明放在模块 README 或配置说明中，不在这里复制一份。
