# 框体页面移动与恢复默认设计

## 目标

在以下七个设置页面增加统一的“解锁/锁定”和“恢复默认”控制：

- 玩家：综合
- 玩家：施法条
- 玩家：能量条
- 玩家：资源条
- 目标：综合
- 目标的目标：综合
- 宠物：综合

“恢复默认”同时恢复当前页面的全部参数和对应框体位置，不提供单独的“重置位置”。微型系统菜单与小地图已有的位置控制保持不变。

## 框体映射

| 设置页面 | 框体 | 位置设置 |
| --- | --- | --- |
| 玩家：综合 | `GwPlayerUnitFrame` | `player_pos` |
| 玩家：施法条 | `GwCastingBarPlayer` | `castingbar_pos` |
| 玩家：能量条 | `GwPlayerPowerBar` | `PowerBar_pos` |
| 玩家：资源条 | `GwPlayerClassPower` | `ClasspowerBar_pos` |
| 目标：综合 | `GwTargetUnitFrame` | `target_pos` |
| 目标的目标：综合 | `GwTargetTargetUnitFrame` | `targettarget_pos` |
| 宠物：综合 | `GwPlayerPetFrame` | `pet_pos` |

## 交互设计

每个页面底部增加“位置”分组，其中“解锁/锁定”和“恢复默认”同排显示。

- “解锁/锁定”复用现有 HUD mover 行为。同一时间只解锁一个框体；再次点击锁定；战斗中拒绝切换并显示提示。
- “恢复默认”恢复当前页面中所有具有 `getDefault` 和 `set` 接口的参数，执行其既有回调以立即应用，再恢复对应 mover 的默认位置。
- 多选下拉项按 `optionsList` 逐项恢复，避免把整张默认表直接写入单个选项。
- 恢复完成后刷新当前设置页面及依赖状态。
- 战斗中触发恢复时，将整次操作排入 GW2_UI 的脱战队列，避免修改受保护框体。

## 实现边界

扩展 `Modules/Settings/HudMoverOptions.lua` 中现有的通用 mover 控制，不在七个页面分别维护重复回调。页面通过配置表声明面板、框体和位置设置的映射。

玩家资源子页面来自 `settingsTab.gwPlusPlayerResourcePanels`，其余页面来自 `settingsTab.gwPlusEmbeddedPanels`。控制必须在框体主菜单构建视图前加入，使目标、目标的目标和宠物的“综合”视图能自然包含它们。

页面级恢复只处理当前页面拥有的选项，不调用 GW2_UI 的全配置恢复，不影响其他页面或配置方案。控制按钮、标题等无值选项不参与参数恢复。

## 验证

自动化回归覆盖以下行为：

- 七个页面均出现一组“解锁/锁定”和“恢复默认”。
- 每个按钮操作正确的框体和位置设置。
- 普通选项及多选项恢复默认并执行应用回调。
- 恢复默认同时更新 mover、保存位置和布局匹配数据。
- 战斗中恢复进入脱战队列。
- 现有微型系统菜单、小地图 mover 测试继续通过。
- 玩家资源页面的既有回归测试继续通过。
