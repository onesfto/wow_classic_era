# 冷却闪烁 GWUI 样式设计

## 目标

将冷却完成提示图标改为与 GWUI 一致的方形图标样式，同时让用户可在设置中选择技能名称显示在图标上方、中央或下方。

## 范围

- 图标采用 GWUI 的深色半透明底板与细边框。
- 图标内容向内缩进并裁切边缘，避免原始图标边框与 GWUI 外框重叠。
- 新增持久化设置项 `spellNamePosition`，默认值为 `上方`。
- 名称位置为 `上方`、`居中`、`下方`；仍由既有“显示技能名称”开关控制。

## 不在范围内

- 不改变冷却监听、队列、动画时长、大小、透明度或移动方式。
- 不新增素材、主题配置或独立的外观选项。

## 实现约束

- 仅修改 `Modules/CooldownPulse/CooldownPulse.lua` 与 `Modules/CooldownPulse/Options.lua`。
- 使用 GWUI 已提供的边框组件；若组件不可用，提示图标仍须可正常显示。
- 名称位置变化应立即应用于当前提示与测试提示。

## 验收标准

1. 冷却提示图标有 GWUI 风格的深色底板、细边框及裁切后的图标内容。
2. 设置中可选“上方”“居中”“下方”，并会即时改变名称锚点。
3. 关闭“显示技能名称”后，所有位置均不显示名称。
4. 原有解锁、拖动、测试动画及冷却完成提示保持可用。
