# GW2_UI_PLUS 框体菜单设计

## 目标

在 GW2_UI 设置窗口中新增一个与现有 Action Bar 顶级框体一致的“框体”标签，集中提供玩家、目标、宠物和小队设置入口。

## 界面

- 顶级标签名称为“框体”。
- “框体”标签使用：
  `Interface/AddOns/GW2_UI/textures/uistuff/tabicon_profiles.png`。
- 现有 Action Bar 标签改用：
  `Interface/AddOns/GW2_UI/textures/character/tabicon-glyph.png`。
- GW2_UI 原“配置”标签改用：
  `Interface/AddOns/GW2_UI/textures/Auction/tabicon_sell.png`。
- GW2_UI 原“设置”标签图标保持不变。
- 左侧菜单依次为：
  1. 玩家（可展开）
     - 综合
     - 资源条
     - 光环
  2. 目标
  3. 宠物
  4. 小队
- 左侧按钮的尺寸、间距、悬停纹理和选中高亮与 Action Bar 顶级框体保持一致。
- 打开标签时默认选择“玩家 > 综合”。

## 页面来源

不复制 GW2_UI 的配置逻辑，也不另建第二套配置存取逻辑。菜单复用设置窗口初始化时已经创建的原生页面和设置项：

- 玩家 > 综合：`player_general`
- 玩家 > 资源条：`player_classpower`
- 玩家 > 光环：`player_aura`
- 目标：`target_general`
- 合并到目标面板末尾的设置项：`target_of_target`
- 宠物：`player_pet`
- 小队：`party_general`

所有 getter、setter、依赖关系、回调和重载提示继续由 GW2_UI 原生实现负责。

“目标的目标”不作为菜单或独立页面显示。只把它的原生设置控件追加到目标面板的数据源末尾；不迁移它的页面标题、说明和面包屑。

玩家、目标、宠物和“目标的目标”中的“隐藏器”设置均不在“框体”标签中显示。

## 集成方式

- `MainMenu/MainMenu.lua` 负责框体标签、左侧菜单、原生页面迁移、设置项合并和“隐藏器”过滤。
- `MainMenu/SettingsIcon.lua` 只负责在 GW2_UI_PLUS 侧把原“配置”标签按钮的图标替换为 `tabicon_sell.png`。
- Action Bar 标签图标在 `ActionBar/Options.lua` 中替换为 `tabicon-glyph.png`。
- 模块暴露构建函数，由 `core.lua` 在 Action Bar 顶级标签之后注册。
- 通过设置菜单现有数据源定位所需 `panelId`，取得并复用页面框体。
- 进入“框体”时，把当前页面临时迁移到新标签并按内容区重新锚定；切换左侧菜单时先恢复上一页，再迁移下一页。
- 离开“框体”标签时，将已迁移页面恢复到原父级、原锚点和原显示状态，保证原设置入口仍可正常打开。
- 玩家按钮使用原生设置菜单相同的父子菜单交互；点击玩家或其展开箭头时显示三个子菜单，点击子菜单切换对应页面。
- 构建框体标签前，把 `target_of_target` 中非“隐藏器”的设置项按原顺序并入 `target_general` 的选项列表和滚动数据源。合并后仍保留原控件对象及注册关系。
- 合并操作必须具备幂等标记，避免重复初始化或重进设置窗口时重复追加设置项。
- “目标的目标”原生页面和原设置入口保持不变，框体标签只借用它的设置控件。
- 本次保留原设置菜单中的“玩家”和“单位框体”入口，方便对照检查；不修改或隐藏原入口。
- 若目标页面未找到，则不创建不完整的框体标签，并输出一次明确的调试提示，避免出现空白页。

## 状态与兼容性

- 顶级标签顺序固定为：框体、动作条、设置、综述、配置。
- 不新增 SavedVariables。
- 不改变任何单位框体配置值或默认值。
- 不修改 GW2_UI 本体目录中的任何文件；图标替换通过 GW2_UI_PLUS 的运行时逻辑完成。
- 页面和合并后的控件仍由 GW2_UI 的设置控件注册表管理，依赖开关、保存和回调行为保持不变。
- Classic Era 没有焦点框体入口；本次范围固定为用户指定的四项。

## 验收标准

1. GW2_UI 设置窗口右侧标签栏按“框体、动作条、设置、综述、配置”排列，“框体”使用 `tabicon_profiles.png`。
2. 点击“框体”后左侧显示玩家、目标、宠物和小队；玩家下有“综合、资源条、光环”三个子菜单，默认选中“综合”。
3. 玩家三个子菜单显示对应原生页面，修改设置与原入口效果一致。
4. 目标面板在原目标设置之后显示“目标的目标”的非“隐藏器”设置，不出现单独的“目标的目标”菜单或页面标题。
5. 玩家、目标、宠物和合并内容中均不显示“隐藏器”。
6. 切换菜单时只有当前页面可见，展开状态和选中高亮正确。
7. 离开“框体”后，原设置入口仍然存在且可用，页面父级与布局均已恢复。
8. Action Bar 标签使用 `tabicon-glyph.png`。
9. 原“配置”标签使用 `tabicon_sell.png`，原“设置”图标不变，替换逻辑只存在于 `MainMenu/SettingsIcon.lua`。
10. GW2_UI 原生文件没有因本功能产生改动，其他设置标签不受影响。
