# GW2_UI_PLUS 玩家资源条页面重组设计

## 目标

重组“框体 → 玩家 → 资源条”页面，把与玩家资源显示有关的设置集中到一个页面，并让普通玩家框体与球状血条可以分别控制。

不修改 `GW2_UI` 原生文件。原生设置项继续使用原 getter、setter、依赖和回调；Plus 自有的血球布局功能继续使用 `GW2_UI_PLUS_ActionBarSV`。

## 页面顺序

资源条页面固定为以下四个大项：

1. 球状血条
2. 施法条
3. 能量条
4. 职业资源条

### 球状血条

显示以下设置：

- 使用球状血条样式
- 为血球预留中间空隙
- 血球缩放
- 显示位移条
- 位移条技能

“使用球状血条样式”继续使用 `PLAYER_AS_TARGET_FRAME` 的反向值：

- 开启：`PLAYER_AS_TARGET_FRAME = false`，显示球状血条。
- 关闭：`PLAYER_AS_TARGET_FRAME = true`，不显示球状血条。

切换球状血条样式需要重新加载界面。打开球状血条时，普通玩家框体是否显示由独立的 Plus 设置决定。

“为血球预留中间空隙”和“血球缩放”直接使用动作条模块已经实现的 `mainBarGlobeGap`、`globeScale`、`ApplyMainBarLayout` 和 `ApplyGlobeScale`，不复制布局算法。

原“显示闪避条”在 Plus 页面中改名为“显示位移条”。“位移条技能”名称保持不变。两项继续读写原生 `showDodgebar` 和 `PLAYER_TRACKED_DODGEBAR_SPELL`。

### 施法条

合并原生 `player_castbar` 页面中的全部可见设置：

- 启用
- 高级施法条
- 施法队列窗口
- 引导法术刻度

本次不移动动作条页面中的“施法条缩放”，因为指定从动作条复用的功能只有血球空隙和血球缩放。

### 能量条

显示：

- 从综合页面移入的原生“能量条”开关（`POWERBAR_ENABLED`）。
- 能量/法力恢复刻度（`PLAYER_ENERGY_MANA_TICK`）。
- 五秒规则剩余时间（`PLAYER_5SR_TIMER`）。
- 仅在战斗中显示能量/法力恢复刻度（`PLAYER_ENERGY_MANA_TICK_HIDE_OFC`）。

这些设置继续使用原生依赖关系。法师的法力条属于本组，不属于职业资源条。

### 职业资源条

保留原 `player_classpower` 中除能量/法力恢复刻度以外的职业资源设置，包括主开关、数值、锚点、偏移、自定义资源条位置和额外资源条。

经典旧世实际显示职业资源条的职业为：

- 盗贼：连击点。
- 德鲁伊：猫形态连击点，以及适用形态下的小型法力条。

经典旧世法师没有职业专属资源条；法师使用“能量条”组中的普通法力条。

## 综合页面调整

从 `player_general` 中移除以下原生设置在本页面的显示：

- `POWERBAR_ENABLED`
- `PLAYER_AS_TARGET_FRAME`
- `showDodgebar`
- `PLAYER_TRACKED_DODGEBAR_SPELL`

这些设置移动到资源条页面，不在综合页面重复显示。

原 `HEALTHGLOBE_ENABLED` 对应的“启用”不再作为球状血条主开关。综合页面顶部改为 Plus 自有的“启用”开关，只控制普通玩家框体。

普通玩家框体开关保存到 `GW2_UI_PLUS_ActionBarSV.normalPlayerFrameEnabled`，默认开启：

- 开启时，保证 `GwPlayerUnitFrame` 已创建并注册单位显示。
- 关闭时，只隐藏并取消注册 `GwPlayerUnitFrame`。
- 不改变球状血条、能量条、职业资源条或施法条的配置。

为了让普通玩家框体和球状血条两种显示可以独立组合，Plus 的玩家显示模式保持原生玩家 HUD 模块可用，并通过 `PLAYER_AS_TARGET_FRAME` 选择是否加载血球。最终允许：

- 普通玩家框体开、球状血条开。
- 普通玩家框体开、球状血条关。
- 普通玩家框体关、球状血条开。
- 普通玩家框体关、球状血条关。

## 数据重组

- 在原生面板全部初始化后定位 `player_general`、`player_classpower` 和 `player_castbar`。
- 按配置键筛选原生选项对象，不复制其配置逻辑。
- 给资源条页面加入四个 Plus 分组标题和三个血球布局选项。
- 按最终顺序重建 `player_classpower.gwOptions` 和滚动数据源。
- 按移出清单重建 `player_general.gwOptions` 和滚动数据源。
- 设置幂等标记，防止重复初始化时重复插入标题或选项。
- 原设置入口仍保留；因为页面对象由原入口与“框体”标签共同复用，重组后的综合和资源条内容在两个入口中保持一致。

## 验收标准

1. “资源条”页面依次显示“球状血条、施法条、能量条、职业资源条”。
2. 球状血条组包含指定的五项，且“显示闪避条”显示为“显示位移条”。
3. 血球空隙和缩放与动作条主动作条页面读写同一份 Plus 配置。
4. 施法条组显示原生玩家施法条设置。
5. 能量条开关不再出现在综合页面，只在能量条组显示。
6. “禁用球状血条样式”、位移条开关和位移条技能不再出现在综合页面。
7. 综合页面“启用”只控制普通玩家框体，不改变球状血条。
8. 普通玩家框体和球状血条四种开关组合均有明确状态。
9. 经典旧世法师使用能量条（法力条），不要求出现职业资源条框体。
10. `GW2_UI` 原生文件不因本功能产生修改。

按用户要求不增加或运行自动化测试；只执行 Lua 语法和静态差异检查，游戏内表现由用户检查。
