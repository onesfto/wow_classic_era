# 本地音乐播放器设计

## 目标

在经典旧世客户端中新增独立插件 `LocalMusicPlayer`。玩家可以在游戏内打开类似 Listen1 的播放器窗口，浏览默认加载的魔兽原声和导入的本地音乐，并完成常见播放控制。

## 功能范围

- 默认加载一组经典旧世客户端自带音乐。
- 左侧按“全部 / 魔兽原声 / 本地音乐”筛选，中间显示歌曲列表。
- 点击歌曲播放，底部提供上一首、播放/暂停、下一首和播放模式按钮。
- 播放模式包含列表循环、单曲循环和随机播放。
- 显示当前歌曲、来源、播放时间和进度。
- 提供主音量滑块。
- 通过小地图按钮或 `/lmp`、`/musicplayer` 打开播放器。
- 将 `.mp3` 或 `.ogg` 放入插件的 `Music` 目录，运行 `ImportMusic.command` 后生成本地曲库；重新加载界面后可播放。

## WoW API 限制

WoW 插件无法在运行时扫描本地目录，也没有从指定时间点恢复声音文件的 API。因此导入脚本在游戏外生成静态歌曲清单；“暂停”会停止当前声音，再次播放时从歌曲开头重新开始。该行为会在暂停按钮的提示中明确说明。

## 结构

- `LocalMusicPlayer.toc`：插件元数据、保存变量和文件加载顺序。
- `Core.lua`：歌曲注册、播放器状态机、播放模式、计时器和斜杠命令。
- `BuiltinTracks.lua`：默认魔兽原声清单。
- `LocalTracks.lua`：由导入脚本生成的本地曲库。
- `UI.lua`：主窗口、筛选列表、歌曲列表、播放栏和小地图入口。
- `ImportMusic.command`：扫描 `Music` 目录，用 `ffprobe` 获取时长并生成 `LocalTracks.lua`。
- `tests/test_player.lua`：使用伪造的 WoW API 验证播放器核心行为。

## 状态和数据流

每首歌曲包含 `title`、`artist`、`path`、`duration` 和 `source`。核心状态保存当前索引、播放状态、声音句柄、开始时间和播放模式。UI 只调用核心公开方法，并通过状态变化回调刷新。

播放时调用 `PlaySoundFile(path, "Master", false, true)` 获取声音句柄，通过 `StopSound(handle)` 停止。歌曲时长到达后，计时器按照当前模式选择下一首。切歌、暂停或停止时先取消旧计时器，避免重复回调。

## 错误处理

- 空曲库或无效索引不调用播放 API。
- 音频文件无法播放时保持停止状态，并在聊天窗口输出歌曲名和路径。
- 本地导入时忽略非 `.mp3`、`.ogg` 文件；缺少 `ffprobe` 时给出安装提示且不覆盖现有曲库。
- 随机模式在歌曲数大于一时避免连续选择同一首。

## 验收

- Lua 文件能通过 `luac -p`。
- 自动化测试覆盖默认曲库、播放/暂停、前后切歌、三种播放模式和失败播放。
- `.toc` 接口版本与当前经典旧世客户端一致。
- 导入脚本能在临时插件副本中从测试音频生成合法 `LocalTracks.lua`。
- 插件只新增自己的目录与设计/计划文档，不修改现有插件。
