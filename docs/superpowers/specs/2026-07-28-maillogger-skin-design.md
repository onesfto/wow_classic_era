# MailLogger GW2 皮肤设计

## 目标

在 `GW2_UI_PLUS` 中为 MailLogger 2.1.4 提供完整的 GW2 风格皮肤，覆盖设置、交易记录和日历三个窗口及其按钮、下拉框、复选框、输入框和滚动条。实现不得修改 MailLogger 原插件目录中的任何文件。

交易记录窗口底部新增“日历”和“设置”两个入口，排列在“关闭”按钮之前。

## 视觉设计

- 三个窗口移除暴雪对话框背景和红色标题贴图，使用 GW2 标准背景。
- 不套用现有的外置统一标题栏。标题改为窗口内部的深色渐变标题区，使用 GW2 标题字体。
- 标题区保留拖动窗口的能力；关闭操作仍使用窗口底部按钮。
- 正文、标签和按钮文字使用 GW2 字体与颜色，清除原有重阴影。
- 控件和窗口边缘保持至少 5px 的间距，主要内容区使用与 NovaWorldBuffs 主设置界面一致的留白尺度。

## 通用控件标准

在 `skins/Core.lua` 中补充两个共享辅助函数：

- `Skin.SkinDropDown`：调用 GW2 的下拉框皮肤 API，统一背景、箭头和文字。
- `Skin.SkinEditBox`：剥离暴雪输入框材质，应用 GW2 背景与正文文字，并保留输入、数字限制、焦点和原有脚本。

MailLogger 皮肤同时复用现有的 `Skin.SkinButton`、`Skin.SkinClose`、`Skin.SkinCheckBox`、`Skin.SkinScrollBar`、`Skin.SkinFont` 和 `Skin.SkinFrame`。

## 接入方式

新增 `skins/MailLogger.lua`，并在 `GW2_UI_PLUS.toc` 的皮肤内核之后加载。

MailLogger 的三个主窗口及大部分子控件都是匿名对象，无法通过稳定的全局名称访问。皮肤使用以下方式接入：

1. 通过 `Skin.Register("MailLogger", ...)` 接入现有加载调度。
2. 对全局 `MailLoggerFrame` 的 `ADDON_LOADED` 处理安装后置钩子，确保 MailLogger 自己的 `Initialize` 已经完成。
3. 从 `UIParent` 的直接子级中识别 MailLogger 的三个窗口：
   - 设置窗口：380×510。
   - 交易记录窗口：初始为 360×510，皮肤处理后为 470×510。
   - 日历窗口：320×320。
4. 结合窗口尺寸、原始对话框背景材质和特征子控件进行校验，避免误处理其他插件窗口。
5. 递归遍历已确认窗口的子控件，按对象类型和模板特征应用对应通用皮肤。

皮肤不拦截全局 `CreateFrame`，也不复制 MailLogger 的数据或记录逻辑。

## 窗口与交互

### 设置窗口

- 美化背景、内嵌标题区和全部文字。
- 美化所有普通按钮、确认/取消按钮、复选框、角色下拉框、输入框和忽略列表滚动区。
- 保留原有删除角色、清空记录、忽略物品及链接选择行为。

### 交易记录窗口

- 宽度从 360px 调整为 470px，为底部按钮和正文增加合理间距。
- 调整滚动区域宽度，使其随窗口扩展。
- 底部按钮单行排列，顺序为：

  `交易｜邮件｜发件｜收件｜全部｜日历｜设置｜关闭`

- “日历”按钮切换日历窗口显示状态；打开时刷新现有日历数据。
- “设置”按钮切换设置窗口显示状态。
- 新按钮只调用 MailLogger 已有窗口与刷新逻辑，不读写其保存变量。

### 日历窗口

- 美化背景、内嵌标题区、年份与月份下拉框。
- 美化星期标题、42 个日期按钮、全部日期按钮和关闭按钮。
- 不改变可用日期判断、禁用状态或日期点击行为。

## 重建与幂等

MailLogger 在删除角色或清空全部记录后会重新执行设置窗口和交易记录窗口的初始化，留下隐藏的旧窗口并创建新窗口。

皮肤为已处理对象设置私有幂等标记，并给设置窗口内的按钮安装后置点击钩子。按钮原逻辑执行后，皮肤重新扫描三个窗口，只处理尚未美化的新对象。该流程不使用延时器或轮询。

重复打开窗口、重复点击筛选按钮或重复执行扫描，不得叠加背景、标题区、脚本或新按钮。

## 错误处理

- 找不到 `MailLoggerFrame` 或目标窗口时安静返回，不影响 MailLogger 使用。
- 仅在目标对象存在对应 GW2 API 时调用皮肤方法。
- 识别结果不满足窗口特征时不做处理，避免误伤其他界面。
- 新增按钮调用目标窗口前检查窗口和刷新函数是否存在。
- 皮肤执行错误由现有 `Skin.Register` 调度器的保护调用交给 WoW 错误处理器。

## 验收标准

- `skins/Core.lua`、`skins/MailLogger.lua` 和相关 Lua 文件通过 `luac -p`。
- 三个窗口的按钮、下拉框、复选框、输入框和滚动条均呈现 GW2 风格。
- 交易记录窗口底部显示 8 个单行按钮，顺序正确且无重叠。
- “日历”和“设置”按钮能分别切换对应窗口，原有命令和小地图入口继续工作。
- 删除角色或清空记录导致窗口重建后，新窗口仍自动应用皮肤，且无重复元素。
- 对 MailLogger 原目录修改前后的全部文件计算 SHA-256，结果完全一致。
- Git 差异仅包含本任务所需的 `GW2_UI_PLUS` 文件和设计、实施文档，不混入仓库中其他已有改动。
